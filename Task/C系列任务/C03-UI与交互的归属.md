键位；功能
1. adws：方向键移动
基础的移动键位，按下按键之后使角色往指定方向移动。
同时按下按键的逻辑采取速度合成的方式。不按移动键的时候速度向量为0，按下方向键为角色叠加速度向量，并以最终方向向量为准进行移动
2. shift：奔跑/解锁点击移动模式
在没有其他上层UI显示的时候，shift长按动作承担两个功能。一个是开启奔跑。另一个是长按shift时点击地图可通行区域，执行自动寻路。如果目标点可达且距离没有超过限制，则开始自动奔跑前往对应位置。
冲突问题：按下shift和方向键奔跑移动的时候，按下鼠标左键点击地图开始寻路。如果寻路通过，此操作会中断方向键的移动输入，由自动寻路开始接管角色的移动。否则继续由方向键来控制角色移动。
正在自动寻路的时候，按下方向键（如果是方向键输入被自动寻路打断的情况下则判定是否是重新按下方向键）会打断寻路
3. f：交互场景道具
f键是通用的与场景道具交互键，安全通道的出入口会被包装成一个不可见的，不可通过的场景道具。与之交互即可到达安全通道的对端。
4. 其他被包装为事件的“离开活动范围”和“租赁载具”的相关交互在事件章节当中定义
