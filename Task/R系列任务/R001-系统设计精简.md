# 任务背景
游戏的系统设计过于复杂，需要精简
# 核心指导理念
将游戏过程中，涉及剧情和演出的部分全部去除，专心设计肉鸽游戏玩法。简化游戏内容

# 工作方向指导
1. 彻底移除自由探索阶段的设计。在事件之间的动作将全部依靠在地图上点击事件来开始，节约场景设计开销
2. 降维事件的结构。一个事件原先是多个事件片段组合，现在一个事件就是一个独立的单元。因为事件内的对话、交互环节都要被砍掉，事件将单元化。但是依旧保留事件结果设计，即玩家在事件内的不同行为（对话选择不同、战斗结果不同）依然会被记录并影响后续游戏内容


# 工作方法
1. 首先需要详读Design目录下的策划文档，对已有的游戏内容有充分理解
2. 任务当中提到的术语在Design文档中找解释
3. 对原文档不要进行任何改动，有任何修改意见，阅读Tool目录下的缺口决策系统的说明文档，将问题按照规范呈报，然后启动填写器供我审阅
