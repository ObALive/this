# 游戏设计文档库（系统 Wiki）

本目录是**全局性、持续维护**的游戏设计文档库，定位为开发团队使用的系统 wiki。各系统的设计内容长期在此生长、修订、维护，跨任务共享。

本库的目录与文件按 `Rules/05_文档库组织规范.md` 组织。库内文档的写法按 `Rules/03_文档编辑规范.md` 执行。本文件只登记本库的定位、分层实例与当前状态，不承载规则条款。

## 一、本库承载的内容

本库承接策划流程第 2～5 步（游戏设计纲要 → 系统架构设计 → 系统关系设计 → 功能需求拆分）的全部落盘文档，回答三个问题：

1. **做什么**：游戏整体与每个系统的设计内容；
2. **有哪些系统**：全量系统清单与分层结构，本库的目录结构即该清单的物理载体；
3. **有哪些注意的交互逻辑和细节**：跨系统的关键交互逻辑与每个界面的交互方式细节。

设计范围约束与文档写法见 `Rules/03_文档编辑规范.md`。

## 二、目录结构总览

```
系统设计文档/
├── README.md                      本文件：库定位、分层实例与当前状态
├── _模板/                         系统设计文档统一模板

├── 01-通用系统/                   区域与位移、信息传递、角色与小队、存档与持久化、设置与辅助功能
├── 02-时间与事件/                 时间机制、日程系统、事件系统（含触发条件子系统）、探索系统
├── 05-运营与经济/                 物品、金钱与货物、委托、背包、仓库与银行
├── 06-战斗/                       时间轴、战场、技能、行动槽连携、装备、遗物、库存联动、敌人AI、战斗目标

```

### 交互与界面规格的归属

界面与操作规格不单独成立章节，各系统的界面与操作规格由该系统设计文档承接；跨系统的全局交互规范由 `00-总览/01_设计原则与跨系统交互逻辑.md` 维护。

全量界面清单独立成文，见 `架构设计文档/界面索引.md`；本库各系统设计文档只承接该界面的内部布局、字段与操作细节（S02 裁定，见 `00-总览/03_设计决策记录.md` 决策 94）。

全量系统清单与系统关系见 `00-总览/00_系统全景图.md`。
