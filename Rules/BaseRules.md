# 规范入口

本工作区的全部规范以 `Rules/` 目录为唯一权威落点。本文件是入口指针，只列规范清单与读取顺序，条款内容一律以各规范文件为准。

## 一、接到任务后的读取顺序

1. 读 `Rules/README.md` 规范索引，按四步判定得出本次任务的规范适用清单；
2. 读 `Rules/01_规范总则.md` 与 `Rules/02_任务执行规范.md`，这两条为全部任务的必读项；
3. 任务涉及文档编写或修订时，读 `Rules/03_文档编辑规范.md`；
4. 任务要写入 `Rules/` 目录时，读 `Rules/04_规范目录维护规范.md`；
5. 判断存疑时取并集，宁可多读，不得凭印象跳过。

## 二、规范清单

| 编号 | 名称 | 权威文件 | 适用场景 |
| --- | --- | --- | --- |
| NR-01 | 规范总则 | `Rules/01_规范总则.md` | 全部任务。目录边界、文档体系总原则、冲突优先级、禁止行为总则 |
| NR-02 | 任务执行规范 | `Rules/02_任务执行规范.md` | 全部任务的执行过程。任务启动、产物落点、文件隔离与命名、状态与断点、完成标准、权限与审计、异常处理、任务报告、多任务隔离 |
| NR-03 | 文档编辑规范 | `Rules/03_文档编辑规范.md` | 编写、修订或评审策划文档与任务书。正文写什么与不写什么、文体禁令、四层文档边界、系统与架构设计稿写法、需求追踪、缺口与裁定对接 |
| NR-04 | 规范目录维护规范 | `Rules/04_规范目录维护规范.md` | 对 `Rules/` 的任何写入动作。新规范的落盘流程、条款写法、修订废弃与合并、覆盖前留档、审计要求 |

## 三、冲突时的执行顺序

```
1. 用户明确指令
2. 任务书授权
3. 规范目录（Rules/）
4. 目录内既有惯例
5. 智能体默认行为
```

任何低优先级规则不得覆盖高优先级要求。判定的附带规则见 `Rules/01_规范总则.md` 第三章。
