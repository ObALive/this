# 对象组件与场景承载类型代码设计案

对象侧的坐标、纹理、转向、属性、量表和技能槽都是 MetaObjectComponent 的派生组件，运行时被角色 MetaObjectInstance 组合持有。MetaObjectPreset 是独立的场景 MonoBehaviour，负责创建实例并把这些普通 C# 组件绑定到 Grid、Transform 和渲染器；它与组件之间是承载与引用关系。量表与技能槽的内部行为分别见[量表](75_量表组件与生命显示代码设计案.md)和[技能槽](80_基础技能槽与待机动作代码设计案.md)，本篇只交代它们在对象侧的类型位置。

## 类型归属与组件层级

以下类和数据类型均属于 Assembly-CSharp 的全局命名空间。基类的公共机制只在[对象底座](10_MetaObject类型与组件底座代码设计案.md)定义其主要说明。

| 类型 | 直接基类或形态 | 归属与用途 |
| --- | --- | --- |
| MetaObjectPreset | MonoBehaviour | 场景 GameObject 上的承载，持有 definition 引用和运行 instance；负责 Grid/Renderer 查询和绑定 |
| SceneCoordinateComponentDefinition | MetaObjectComponentDefinition | 定义清单中的配置，保存锚点偏移，创建下列运行组件 |
| SceneCoordinateComponent | MetaObjectComponent | 由运行对象持有，维护当前格和场景锚点 |
| SceneTextureComponentDefinition | MetaObjectComponentDefinition | 保存 Sprite、动画预制体、路径和初始朝向配置 |
| SceneTextureComponent | MetaObjectComponent | 由运行对象持有，拥有自己创建的动画显示实例，引用承载渲染器 |
| MovementFacingComponentDefinition | MetaObjectComponentDefinition | 创建主动移动转向组件 |
| MovementFacingComponent | MetaObjectComponent | 订阅对象内主动移动完成通知，调用同对象纹理组件 |
| AttributeComponentDefinition | MetaObjectComponentDefinition | 保存三项基础值，每次创建独立运行组件 |
| AttributeComponent | MetaObjectComponent | 由运行对象持有基础值和按来源记录的运行修正 |
| MetaObjectMeterComponentDefinition | MetaObjectComponentDefinition | 保存用途标识、上下限与初值，每次创建独立量表组件 |
| MetaObjectMeterComponent | MetaObjectComponent | 由运行对象持有，私有组合既有 MeterComponent 作为唯一数值容器 |
| BasicSkillSlotsComponentDefinition | MetaObjectComponentDefinition | 保存四个动作定义引用，每次创建独立槽组件 |
| BasicSkillSlotsComponent | MetaObjectComponent | 由运行对象持有，四槽各持有独占的动作实例 |
| CellChanged / MovementCompleted | 两个 readonly struct | 分别承载格坐标变化、主动移动完成的旧格/新格，作为对象内消息 |
| HorizontalFacing / CharacterAttribute | 两个 enum | 前者为左右朝向；后者为 ActionPoints、Strength、ActionSpeed，均不是可挂载组件 |

各 Definition 重写的 CreateComponent 声明源自 MetaObjectComponentDefinition。运行组件重写的 OnBind/OnUnbind/OnAttached/OnDetached 源自 MetaObjectComponent。MetaObjectPreset 本身不派生自 MetaObjectInstance，也不放进该实例的组件字典。角色对象中另有 MovementActionComponent 与 BasicSkillSlotsComponent 两个动作相关持有组件：前者持有一个移动动作，后者持有四个槽位动作，二者并列且都不继承 MetaActionComponent，其动作侧派生和生命周期见[动作体系](30_MetaAction派生类型与动作组件代码设计案.md)与[技能槽](80_基础技能槽与待机动作代码设计案.md)。

## MetaObjectPreset 的绑定与实例所有权

| 声明类与关键方法 | 上下游 | 当前职责 |
| --- | --- | --- |
| MetaObjectPreset.Awake / Start / OnSceneLoaded | Unity 生命周期或场景事件 → TryBind | 初次创建与地图缺失后的重试 |
| MetaObjectPreset.TryBind | RebuildInstance → definition.CreateInstance；组件 Bind | 创建实例，初始化格坐标，逐个场景绑定 |
| MetaObjectPreset.Rebuild | UnbindComponents、DisposeInstance → TryBind | 保留最新逻辑格后整体换实例 |
| MetaObjectPreset.SetCell / MoveToCell / BindGrid | 外部定位调用 → 坐标组件 | 暂存未绑定输入或转交已绑定组件 |
| MetaObjectPreset.OnDestroy | Unity → 解绑、Dispose | 释放持有的运行实例 |

显式 Grid 引用优先，其次找父级、当前场景和指定地图场景；兜底只接受全场景唯一 Grid，多个候选不猜测。首次绑定取暂存格输入，否则用当前世界位置换算；已有绑定重复调用保留组件当前格。若含坐标组件而 Grid 不可用，保留 pendingBinding，在 Start 和场景加载后重试。

缺定义时建立空实例并记录错误，这只能帮助暴露接线问题，不代表角色能力就绪。重建先保存组件当前格，再解绑、释放旧实例并重建，因此不能从带偏移的世界位置误反推角色位置。禁用承载只解除场景加载订阅，销毁才整体释放；当前流程也不保存实例状态到存档。

## 坐标、消息与显示组件的分工

SceneCoordinateComponent.SetCell 声明并维护坐标写入：先保存逻辑格，再通过 ApplyToScene 把 Transform 移到 Grid 格中心加世界偏移，格变化时 Publish CellChanged。未绑定仅保留逻辑状态，缺 Grid 时记录错误、场景位置不变。该入口不校验地图边界或行动资格。

同类的 MoveToCell 调用 SetCell，在已绑定且格子实际变化后发布 MovementCompleted。MovementFacingComponent 在 OnAttached 订阅这一消息，处理器 OnMovementCompleted 只在水平变化且仍绑定时读取 Owner 的纹理组件并 SetFacing；竖直移动保持朝向。SetCell 的普通定位、初始化或被动位移不会自动产生这条主动移动通知。

SceneTextureComponent.OnBind、SetAnimationPrefab、SetTexture、SetTexturePath 和 SetFacing 都声明在纹理运行组件中；配置类不负责修改场景。显示优先采用有效动画预制体，其次直接 Sprite，再尝试路径加载。动画预制体要求活跃、具有 SpriteRenderer、带 Controller 的 Animator，并且不含 MetaObjectPreset。创建成功后替换旧实例，隐藏原渲染器；无效资源尽量保留原显示。

动画显示实例由 SceneTextureComponent 创建并拥有，根局部位置归零，内部层级、旋转和缩放保留。ReleaseAnimation 在切回静态、解绑时恢复原渲染器并释放实例；运行期先隐藏/脱离父级，再延迟销毁。左右朝向基于各渲染器原始 flipX 镜像，改变显示不改变逻辑格。LoadSprite 的 Resources 分支可运行，普通 Assets 路径的 AssetDatabase 回退仅在 UNITY_EDITOR；不能把任意编辑器路径解析视为播放器能力。

## AttributeComponent 的取值与方法归属

| 声明类与方法 | 调用/数据关系 | 行为边界 |
| --- | --- | --- |
| AttributeComponentDefinition.CreateComponent | 对象定义创建 → AttributeComponent 构造 | 复制行动力、力量、速度基础值 |
| AttributeComponent.GetBaseValue / GetValue | 详情或玩法 → 基础值/来源修正 | 当前值为基础值加各来源贡献；查询不消耗、不钳位、不取整 |
| AttributeComponent.SetModifier / RemoveModifiers | 外部来源提供标识与贡献 | 同来源同属性覆盖，设零移除该项，全部归零后移除来源；可一次撤销整来源 |
| AttributeComponent.OnDetached | 底座 Detach 调用的重写钩子 | 卸载清空来源；单纯解绑保留 |

基础值与修正必须有限，来源非空且区分大小写。GetValue 按来源 ordinal 顺序以 double 汇总，超出 float 范围抛 OverflowException；无自动回退或回滚。每个运行角色修正独立，不改共享定义。

UnitDetailsPanel.Refresh 读取时间轴当前行动者的三项属性，捕获汇总溢出后显示错误并禁用移动按钮；DebugPanel.GetCharacterDetailsText 仍是没有启用详情面板时的调试回退，该方法不捕获汇总溢出。MovementRange.Refresh 读取行动力（术语表 T-036）用于范围，溢出时失效并清空。三个消费者的失败处理不同，详见[单位详情面板](70_UnitDetailsPanel与移动选择界面代码设计案.md)。当前未见装备/效果自动注册来源、力量投掷和速度补正的接线，底层可取值与消费者已实现须分开理解。

属性与量表是两套数值：AttributeComponent 保存由配置提供、按来源修正的固定属性，查询不消耗也不钳位；MetaObjectMeterComponent 保存有上下限、可增减的当前值。二者不互相复制，生命也不参与移动范围或行动速度计算。量表的结构与显示见[量表专题](75_量表组件与生命显示代码设计案.md)。
