# 代码说明文档维护规则

本目录同时维护专题代码说明、横向扩展内容数据库及其配套说明。以下规则来自用户在 2026-10-30 的明确要求。

- 更新本目录代码说明文档时，必须一并核对 `横向扩展内容库/横向扩展内容.sqlite`。涉及既有类别的类型、协议、标识、实现状态、限制或源码定位变动时，同步更新数据库、`seed.py` 和导出说明；无相关变动时说明已核对、无需变更。
- 默认只维护已有内容表及其条目，不创建新内容表。发现值得单独建表的新类别时，先说明候选类别、纳入理由、已有表为何不能承载、拟登记成员和字段，再询问用户；只有收到明确同意后才能增加该类别及内容表。
- 用户尚未答复时，继续处理已授权的既有表与文档更新；把候选类别记录为文字待确认事项，不通过改 `seed.py`、执行 SQL 或初始化工具绕过询问。
- 固定的 `HorizontalFacing`（Right/Left）已由用户明确排除，不重新登记为扩展类别。
- 正式数据库唯一维护位置为本目录的 `横向扩展内容库/`，游戏源码根目录为 `D:/myspace/Git/mygame`。旧的 `Dsh/Output/横向扩展内容库-20261030/` 不再作为维护入口。
- 具体更新和核验步骤见 `横向扩展内容库/README.md`。保留人工备注、负责人、优先级及计划条目；核对事实以当前源码为准，说明文档提供解释依据。
