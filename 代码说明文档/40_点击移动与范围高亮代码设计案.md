# 点击移动与范围高亮代码设计案

## 地图与角色何时可用

地图转换器启用时读取指定 Tilemap 的已绘制瓦片，建立以二维格坐标查询的记录。绘制层必须属于当前 Grid、与其世界变换对齐，默认地形标识不能为空，映射不能包含空项或重复瓦片；地图只接受 z=0。重建先提升版本并清空旧快照，失败保留错误原因且停止查询，避免继续使用过期地图。

每个已绘制地格记录映射后的地形标识，未映射的使用默认值；空洞和绘制区域外没有记录。地图修改后需要显式 RebuildMap，转换器没有持续监听笔刷变化。当前地图配置的默认地形是 ground、映射表为空。转换层提供查询数据，尚未通知状态系统施加沼泽减速等地形效果。

可接受输入要求移动控制器启用且角色持有有效动作；带时间轴时还须由它确认该角色当前可控。查询目标进一步要求承载仍绑定、运行实例未被替换、地图就绪，并具备已绑定坐标和属性组件。动作和场景装配细节分别见[动作专题](30_动作执行与交接代码设计案.md)与[对象专题](10_对象与场景显示代码设计案.md)。

## 范围怎样确定和更新

范围组件读取行动力（术语表 T-036）的当前值，负值按零，取整数部分作为最大距离。它遍历地图现有记录，选出与原格曼哈顿距离不超过上限的格子，并排除原格；对外列表按 y 再按 x 排序，成员判断使用同一集合。

范围是派生数据，缓存来源包括地图及其版本、坐标/属性组件实例、当前格和当前行动力。LateUpdate 与每次目标查询、受理前的检查都会刷新；输入相同则复用，改变时重算并增加范围版本。缺少能力、组件禁用或行动力汇总溢出时清空范围并标为未就绪。由此，按住鼠标期间属性变化不仅改变下一次受理，也会使原按压失效。

目前的距离筛选没有路径搜索、障碍、占格或累计地形成本。目标在地图上存在且直角距离合格，就可能进入范围；即使中间隔着空洞，也没有连通性过滤。这个集合解释当前可选目的格，不能作为已经实现路径可达性的证据。

## 一次点按如何确认或取消

输入适配器用旧输入后端逐帧采集鼠标位置与左键阶段。它先即时检查调试面板区域和 EventSystem 下 GraphicRaycaster 的界面命中，遮挡时不接收地格。相机屏幕范围有效后，把射线与 Grid 所在平面相交并换算格坐标，再检查该格是否属于当前动作可选集合。

原格按下时记录该格、范围版本与行动机会编号。按住期间只要离开该格、被界面遮挡、失去可选性、范围版本或机会改变，就取消本次按压；移回也不会恢复。只有原格内松开且按压仍有效，才清除指针状态并发布一次 CellSelected。失焦、应用暂停、禁用也会清除指针状态。

悬停与按压状态分别供覆盖层显示。SubmitScreenPoint 可模拟一次完整点按，返回 true 只表示发布了选格意图；DispatchedCount 同样统计意图派发，不是成功移动次数。普通点按直接提交目的格，当前没有完整战斗移动预览再确认的阶段，也没有本流程的键盘或手柄映射。

## 移动受理、结果与失败

移动控制器订阅选格事件，禁用时解除订阅。每次请求记录目的格，取得角色所持动作并构造执行上下文。非当前可控角色返回 OutOfTurn；动作侧还核对运行实例、机会和执行锁，防止旧机会继续使用。

具体移动能力依次确认地图、坐标和属性就绪，目的格存在、不同于原格且处于当前范围。动作目标校验通过后，执行效果仍会重新验证，再由坐标组件的 MoveToCell 更新位置并发出通知；生效期间实例失效或结果与目的格不符会抛异常，交由动作生命周期停止调度。

正常结果区分成功移动、已在原格、未就绪、地图外、超范围、非本方机会和动作拒绝。普通鼠标流程已经排除原格和范围外格，直接方法调用仍可得到这些拒绝结果。拒绝通常在生效前发生，保持坐标和行动机会；执行中异常可能已有部分效果，完整处理见[动作专题](30_动作执行与交接代码设计案.md)。

成功后控制器刷新范围并通知时间轴控制器。动作本身已经完成实际回排，该通知用于登记最近动作和取消旧指针，不能理解为由界面推进时间轴。请求结果及错误可从 LastResult/LastError 查询；当前未见把所有拒绝原因转为玩家提示弹窗的统一通道。

## 高亮和按压反馈怎样呈现

覆盖层从移动动作查询当前目标集合，按范围版本决定是否重新绘制。角色不可控、查询失败或缺边框瓦片时清空显示。有效时在地图 Grid 下创建独立 Tilemap，把边框瓦片绘制在目的格，使用配置排序层、顺序和整体色调，不改原地图瓦片。

常驻场景为三角色分别绑定 MovementRange、移动输入/控制器与覆盖层，边框资源指向 MovementRangeTile。整体 tint 的 alpha 为 0.8，普通、悬停和按压透明度分别为 0.5、0.8、1，最终再乘整体色调。反馈切换先恢复旧强调格，再处理新格；目标失去可选性时撤掉强调。

渲染配置为 Front1、顺序 1，覆盖层使用承载渲染器的共享材质，瓦片变换随 Grid 单元大小缩放。禁用清空，销毁释放创建的 Tilemap，换 Grid 时释放后重建。当前两份树预制体有未提交改动；这些排序输入已静态核对，但是否被树冠遮挡、边框与鼠标反馈的实际观感尚未运行验证。
