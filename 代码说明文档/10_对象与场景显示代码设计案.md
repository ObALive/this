# 对象与场景显示代码设计案

## 入口与生效条件

场景承载 `MetaObjectPreset` 默认在 Awake 尝试创建实例并绑定。若含坐标组件而地图 Grid 尚不可用，会保留待绑定状态，在 Start 和场景加载事件后重试。Grid 优先使用显式引用，再找父级、当前场景和指定地图场景；最后只有全场景唯一 Grid 时才采用，多个 Grid 无法确定时记录错误。

首次绑定的格坐标优先使用绑定前暂存的 SetCell 输入，否则由物体世界位置换算。已经绑定后重复 TryBind 保留当前坐标。角色属性和所持动作的配置来源由同一对象定义提供，见[属性专题](20_固定属性取值代码设计案.md)与[动作专题](30_动作执行与交接代码设计案.md)。

## 创建、组件协作与清理

定义按配置清单逐项创建运行组件。空配置或返回空组件时记录问题并跳过；创建或挂载抛异常会释放已创建的实例并继续抛出。对象侧和动作侧配置不能混用。定义没有接线时，场景承载记录错误并建立空实例，因此“已经有实例”并不代表移动能力齐全。

运行实例按具体组件类型持有能力。同类型的新组件替换旧组件，旧组件先卸载；重复添加同一个组件实例不重做生命周期。不同对象不能同时持有同一个组件实例，清理期间与同类型挂载回调重入会被拒绝。按基类或接口查询不会自动找到具体子类组件。

组件先挂载到运行实例，再绑定到场景；解绑保留运行归属，卸载解除归属并清理订阅。场景承载绑定时遍历当前构成，运行实例单独新增组件仅完成挂载，调用方不能据此假定其已经获得场景绑定。重建场景承载时先保存当前格坐标，解绑并释放旧实例，再从定义创建新实例。

对象内消息帮助坐标与显示能力协作，消息按精确类型限定在同一运行对象内。发布时按订阅顺序同步执行快照；新订阅从下一次发布生效，已取消或卸载的订阅立即失效。单个处理器抛错会记录异常并继续通知其他处理器，已经发生的状态修改不会回滚。解绑本身保留对象内订阅，处理场景的组件需要自行检查绑定状态；卸载会自动清除该组件订阅。

实例整体释放时先清空构成和订阅，再逐个卸载组件；单个清理异常不会阻止其余组件清理，最后以聚合异常报告。场景承载在销毁时解绑并释放；仅禁用承载会解除场景加载事件订阅，不能等同于销毁实例。

## 格子位置、显示与转向

坐标组件持有逻辑格坐标。SetCell 先记录新格子，再用 Grid 格中心加固定世界偏移更新场景锚点；坐标变化后向对象内部发布 CellChanged。未绑定时只保留逻辑值，绑定后再应用。缺 Grid 时记录错误，场景位置不更新；该低层入口自身不检查地图边界、行动力或阻挡，玩家移动由[移动受理流程](40_点击移动与范围高亮代码设计案.md)先校验。

主动移动使用 MoveToCell，在定位后且确实换格、仍已绑定时额外发布 MovementCompleted。转向组件只订阅主动移动通知，水平方向改变时设置左右朝向，竖直移动保持朝向；初始化、普通定位或被动位移通过 SetCell 时不会隐式套用主动转向。

显示优先使用动画预制体，其次直接 Sprite，再按路径加载。动画资源必须是含 SpriteRenderer 和有效 Animator Controller 的纯显示预制体，不能包含对象承载；切换时先验证并创建，再替换旧显示，失败尽量保留原显示。动画实例挂在承载下面，根局部位置归零，内部层级、旋转与缩放保持。静态渲染器暂时隐藏，解绑或切回静态显示时恢复并释放动画实例。

朝向在各渲染器原始 flipX 的基础上镜像，换资源时继续应用当前朝向。运行期销毁动画时先隐藏、脱离父级，再等待 Unity 销毁；编辑器非播放时即时销毁。路径解析先尝试 Resources，普通 Assets 路径的 AssetDatabase 回退只在编辑器编译。直接引用的 Sprite 和预制体是当前角色配置的主要资源入口，不能把任意编辑器路径加载成功推为播放器支持。

## 实际配置与行为边界

常驻场景的 Player、Unit_02_Timeline、Unit_03_Timeline 分别引用三份定义；均含坐标、纹理、属性、移动转向和移动动作持有组件。坐标偏移均为零，显示配置引用同一动画预制体。地图由 `01.Field` 的 Grid 提供，承载的显式 Grid 留空，通过场景名寻找。

静态绑定证明配置有落点，显示、动画播放和地图加载后的最终画面尚未运行验证。组件状态没有接入本流程的持久化；共享定义不会因为角色移动而回写坐标。全局组件注册表的强制登记约束尚不能由本地按类型组合机制证明落实；当前直接加载资源和查找场景的方式也未形成架构规定的统一基础设施接入。
