# 基础技能槽与待机动作代码设计案

BasicSkillSlotsComponent 为角色提供固定四槽，每个槽持有自己的动作实例；MovementActionComponent 与其并列，持有一个移动动作。玩家选中槽位后按指向性确认，槽位调用统一发送出口构造并补齐报文，通过动作生命周期和 Router 执行；待机成功后按配置后摇回排。

## 容器、动作与场景适配

这些类型属于 Assembly-CSharp 的全局命名空间。BasicSkillSlotsComponentDefinition、MovementActionComponentDefinition 继承 MetaObjectComponentDefinition，通过 CreateComponent 建立对象侧组件。BasicSkillSlotsComponent 直接继承 MetaObjectComponent；MovementActionComponent 通过 ActionHolderComponent 继承该基类。

```mermaid
classDiagram
  MetaObjectComponent <|-- ActionHolderComponent
  ActionHolderComponent <|-- MovementActionComponent
  MetaObjectComponent <|-- BasicSkillSlotsComponent
  BasicSkillSlotsComponent *-- MetaActionInstance : 每槽独占
  ActionHolderComponent *-- MetaActionInstance : 单个动作
  MetaActionInstance *-- ActionPacketBuilder : 技能参数构造
  MonoBehaviour <|-- SkillSelectionController
  SkillSelectionController ..> BasicSkillSlotsComponent : 查询与发送
  BasicSkillSlotsComponent ..> ActionPacketOutlet : Send
  ActionHolderComponent ..> ActionPacketOutlet : Send
```

槽组件保存定义引用和独立动作实例，角色运行对象负责挂载与释放槽组件。SkillSelectionController 是角色 GameObject 上的场景组件，保存选择槽号、机会和实例引用；BattleTimelineController 在启动时为带槽角色按需添加它，再绑定时间轴。UnitDetailsPanel 将按钮选择转发给该控制器。

## 配置、准备与释放

基础技能采用四槽配置，单项可以为空；构造时复制四个定义引用。Prepare 为尚未创建的动作或 Terminated 动作按各自定义建立新实例。OnAttached、OnBind 及战斗启动调用 Prepare。OnUnbind 终止动作；OnDetached 终止并清空实例数组。

移动容器 OnAttached 按定义创建单个动作，OnBind 补建空动作；Prepare 对已有 Terminated 动作创建新实例。OnUnbind 与 OnDetached 终止并清空所持动作。两类容器各自持有实例，共享动作定义资产。

三名角色各有一个移动容器和一个四槽容器；每名角色第一个槽引用 FixedDamageAction，其余三个槽引用 WaitAction；每个槽仍持有独占运行实例和生命周期，对象指向与伤害见 [95 专题](95_对象指向与固定伤害代码设计案.md)。移动使用 MovementAction 与独立按钮。

## 槽位发送入口

BasicSkillSlotsComponent.TryExecute 按索引取得动作并调用 ActionPacketOutlet.Send，slot 字段使用该槽的零基索引字符串。ActionHolderComponent.TryExecute 发送所持动作，slot 为 Movement。Owner 与 context.Actor 的实例身份统一在共享出口核对，不匹配时返回 NotReady。

共享出口调用动作构造器生成报文，来源和实际目标由出口补齐。动作构造器提供 operation、targetKind、recovery；出口按角色上下文写入 source，并按动作指向性填写或省略 target。之后登记来源，调用 MetaActionInstance.ExecutePacket 进入生命周期，再发送至 Router。字段、快照与执行器匹配以 [90 Router 专题](90_ActionRouterManager与键值报文执行代码设计案.md) 为主要说明。

## 选择、确认与结果

1. SelectSlot 由按钮或数字键 1—4 触发，要求角色绑定、适配器启用、时间轴允许控制、索引有效、动作存在且相态处于 Terminated 以外的状态。它取消移动和前一个槽选择，记录槽号、机会编号与当前角色实例。
2. Cell 指向性由地图高亮和选格流程确认。CharacterMovementController 查询 SelectedCellAction 的目标，构造包含实际目的格及移动能力的上下文，通过 ExecuteCell 交给槽位。
3. None 指向性通过再次选择同一槽调用 Confirm，或由 GridClickInput 将场景左键按松过程交给 ProcessPointer。按下和松开均需满足界面遮挡条件，确认上下文使用当前角色、机会、时间轴与 Router。
4. 生命周期对当前机会加锁，Router 按 operation 调用执行器。成功后时间轴完成回排，控制器清理选择并 NotifyActionFinished；执行器返回拒绝时当前机会保留，选择可以继续等待确认。

SelectedIndex 持续比较当前机会与记录机会、当前角色实例与记录实例。机会切换、实例重建、适配器禁用、应用失焦或暂停会使选择失效或取消；移动选择和右键也清理技能选择。地图输入先处理右键，再交给技能控制器处理 Object 或 None 指向性；未提交时继续地格选格，对象指向性不进入移动选择。完整按压语义见 [60 移动与输入](60_地图与移动适配类型代码设计案.md)。

## 待机报文与界面配置

WaitAction 的定义标识为 ACTION_WAIT，显示名为待机；唯一组件配置为 WaitPacketBuilderDefinition，targetKind 为 None，timing 引用 WaitTiming，后摇 10。WaitPacketBuilder 构造 operation 为 Wait 的参数，槽位添加来源和机会等上下文，省略实际目标。Router 将 Wait 操作交给 WaitEffectExecutor，该执行器返回 Succeeded。生命周期随后按后摇完成行动。

四个底部技能按钮放在 BaseSkills 容器，按定义显示技能名与后摇：第一个为固定伤害、后摇12，其余为待机、后摇10。按钮选中颜色与移动选择一致，交互资格来自当前角色控制权及动作相态。按钮数量、标签索引和背景 Image 接线见 [70 面板专题](70_UnitDetailsPanel与移动选择界面代码设计案.md)。

## 实现范围与核验条件

当前资产提供独立移动和四槽待机；代码同时具备地格槽动作的查询与发送路径。地格槽分支的实际交互核验需要将有效 Cell 动作配置到槽位并运行场景。技能成本、冷却、伤害与反应效果属于未实现能力。选择状态、机会记录与各槽动作生命周期属于运行数据，角色重建和战斗重新装配时按对应生命周期初始化。
