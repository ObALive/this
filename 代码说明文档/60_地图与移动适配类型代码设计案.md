## 类型与场景职责

这些类型属于 Assembly-CSharp。TilemapManager、MovementRange、GridClickInput、CharacterMovementController、MovementRangeOverlay 都继承 MonoBehaviour；MapCellData 是只读结构体。CharacterMovementController 的私有嵌套类 MovementCapability 实现 IMovementCapability，提供目标查询、有效性和目的格校验。

| 持有方 | 持有或引用内容 | 功能 |
| --- | --- | --- |
| TilemapManager | Grid、地图源 Tilemap、只读查询用地格字典 | 将绘制数据转换为地格快照 |
| MovementRange | 坐标和属性引用、地图版本、目标列表与成员集合 | 生成可重建的派生范围 |
| GridClickInput | 相机、调试面板、按压地格、范围版本与机会编号 | 采集设备输入并发布 CellSelected 意图 |
| CharacterMovementController | 角色承载、输入源、时间轴、选择时的实例和机会 | 装配能力及执行上下文，调用移动容器或选中技能槽 |
| MovementRangeOverlay | 自建的 Tilemap GameObject 与渲染缓存 | 画范围、悬停与按压反馈 |
| MovementEffectExecutor | Router 同物体上的共享场景组件 | 校验并提交地格移动 |

## 地图快照与屏幕投影

TilemapManager.OnEnable 调用 RebuildMap。重建先增加 Revision、清空记录并置为未就绪，再要求源 Tilemap 属于当前 Grid、与 Grid 的世界矩阵对齐，默认地形 ID 有效、映射项完整且瓦片唯一。遍历已绘制且 z=0 的瓦片，以映射或默认标识建立 MapCellData；空地图或非法配置形成 LastError 并保持查询关闭。OnDisable 清空快照并增加 Revision，地图编辑后由调用者显式 RebuildMap。

TryGetCell 只查询已记录地格。TryScreenToCell 要求地图就绪、相机有效且点在 pixelRect 内，将屏幕射线与 Grid 的二维平面求交，再通过 WorldToCell 得到地格；实际目标资格由后续范围与执行校验决定。

## 范围计算与缓存

MovementRange.Refresh 要求角色启用且已绑定，地图、坐标、属性可读。行动力汇总溢出时清空范围并记录错误。有效范围采用 `floor(max(0, 当前行动力))` 作为最大曼哈顿距离，只遍历地图已经记录的有限地格，排除角色当前格，再按 y、x 排序。曼哈顿计算使用 long 避免 int 坐标差溢出。

缓存比较地图及 Revision、坐标与属性组件引用、角色地格和行动力值；输入相同时复用结果，变化时重算并增加 Version。Contains 调用 Refresh 读取当前范围。取消移动选择会 ClearSelectionCache，禁用或依赖失效会 Invalidate。范围计算依据地格存在性与曼哈顿距离，地形标识供查询使用；路径、占用和地形累计成本的结算属于当前范围算法以外的能力。

## 选择与地图点按

SelectMovement 要求控制器有效、动作定义有效、时间轴允许操作；选择成功时取消技能选择，并记住机会编号与角色实例。IsMovementSelected 持续复核这两项身份，Update 在失效时取消。取消会清理 GridClickInput 按压、覆盖层和范围缓存。

GridClickInput 使用 Input 鼠标状态。右键优先调用 ProcessCancel，取消移动和技能选择。同帧左键处理先让 SkillSelectionController 尝试确认无目标技能；消费成功则结束该次处理。普通选格要求界面未遮挡、移动或地格技能处于选择态、相机投影有效且目标在当前可选集合。

地格按下时保存 armedCell、SelectionVersion 和 OpportunityId。按住期间移出原格、范围版本变化、机会变化或出现遮挡，按压立即失效；移回原格需要重新按下。原格内有效松开才发布 CellSelected，发布前清理指针，允许订阅方同步移动或清理角色。悬停只在空闲且地格有效时显示。禁用、失焦或暂停会取消按压；这些事件对动作选择的清理由对应控制器负责。

IsScreenPointBlocked 同时检查 DebugPanel 的实际区域与 EventSystem.RaycastAll 返回的 GraphicRaycaster 命中，使用即时射线检测处理 uGUI 遮挡。SubmitScreenPoint 复用按下与松开阶段，可供语义调用。

## 报文发送与实际移动

CharacterMovementController.TryMoveToCell 是正常输入和调试移动共用入口。它记录目的格，建立捕获当前角色实例的 MovementCapability，构造含时间轴和 Router 的 ActionExecutionContext，并复核角色控制权。若有选中的地格技能则调用 SkillSelectionController.ExecuteCell，否则调用 MovementActionComponent 继承的 TryExecute。查询范围时采用相同的动作优先级。

槽位发送出口补齐来源、目标和机会后，经动作生命周期调用 Router.Send。移动执行器要求 targetKind 为 Cell 且 target 可解析，解析注册角色和能力，记录 before，再调用能力 Validate：地图或组件缺失返回 NotReady，地图外返回 InvalidTarget，同格返回 NoChange，范围外返回 OutOfRange。通过后调用 SceneCoordinateComponent.MoveToCell，再核对能力与实际地格；完成或异常路径记录 after。主动移动通知驱动朝向，详见 [20 场景组件](20_对象组件与场景承载类型代码设计案.md)。

| ActionResult | 输入适配层 CellMoveResult |
| --- | --- |
| Succeeded | Moved |
| NoChange | AlreadyThere |
| NotReady | NotReady |
| InvalidTarget | OutsideMap |
| OutOfRange | OutOfRange |
| OutOfTurn | OutOfTurn |
| 其余结果 | ActionRejected |

返回 Moved 后取消两类选择并 NotifyActionFinished。执行异常沿调用栈传播，由生命周期停止时间轴；执行器记录和动作完成之间的边界见 [40 生命周期](40_MetaActionLifecycle统一执行入口代码设计案.md) 与 [90 Router](90_ActionRouterManager与键值报文执行代码设计案.md)。

## 覆盖层生命周期

MovementRangeOverlay.LateUpdate 查询选中动作的地图、格集和版本，版本变化时重画。它在地图 Grid 下创建独立 Tilemap，使用 frameTile、Tint 和格子缩放绘制边框，默认 Sorting Layer 为 Front1、Order 为 1。静态地图数据由 TilemapManager 的源层持有。

普通、悬停、按压透明度分别为 0.5、0.8、1，并乘整体 Tint 的 alpha 0.8。强调格采用 PressedCell 优先于 HoveredCell，并复核当前目标可选。Clear 清瓦片和缓存；禁用时 Clear；切换 Grid 或销毁时 Release 自建物体。frameTile 缺失、地图失效或选择结束时覆盖层清空。
