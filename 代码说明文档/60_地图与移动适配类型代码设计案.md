# 地图与移动适配类型代码设计案

地图和移动适配由场景 MonoBehaviour 组成，它们把界面动作选择、设备输入、绘制层、角色组件和动作接口接起来。CharacterMovementController 持有移动选择状态；选中后 GridClickInput 才产生目的格意图，控制器通过角色所持动作提交请求，其嵌套 MovementCapability 实现动作能力接口；MovementRange 和 MovementRangeOverlay 分别持有按查询生成的范围与显示对象。

## 类型与归属关系

| 类型 | 直接基类或接口 | 所有权与结构职责 |
| --- | --- | --- |
| TilemapManager | MonoBehaviour | Grid 所在 GameObject 上的转换器，引用绘制 Tilemap，持有格坐标到 MapCellData 的快照字典 |
| MapCellData | readonly struct | 只含 Cell/TerrainId 的查询记录，不携带地图写入口 |
| TilemapManager.TileTerrainMapping | 私有嵌套 struct | 瓦片到地形标识的配置记录 |
| GridClickInput | MonoBehaviour | 角色承载上的输入组件，引用相机、调试面板、控制器和承载，持有当前按压状态，发布 CellSelected |
| CharacterMovementController | MonoBehaviour | 持有 movementSelected、selectedOpportunity、selectedInstance，引用时间轴和承载；订阅目的格意图并构造执行上下文 |
| CharacterMovementController.MovementCapability | 私有嵌套 sealed class : IMovementCapability | 引用外部控制器与被捕获的角色实例；提供目标查询、校验和实际位移，不是 MetaObjectComponent |
| SkillSelectionController | MonoBehaviour | 技能槽选择的场景适配器，持有选中槽号、机会与角色实例；在地格指向时把目标查询与提交接回本专题的移动链路 |
| CellMoveResult | enum | 输入适配层结果，与动作侧 ActionResult 分开映射 |
| MovementRange | MonoBehaviour | 引用当前地图、坐标与属性组件，持有可重建的列表、成员集合和版本 |
| MovementRangeOverlay | MonoBehaviour | 持有自己创建的覆盖 Tilemap，引用地图 Grid、输入及移动控制器；只显示被允许的格子 |

这些 MonoBehaviour 彼此通过 GetComponent 或序列化引用协作，不相互继承，也不在普通对象的 MetaObjectComponent 字典中。RequireComponent 表达同 GameObject 的装配依赖，不是 C# 继承。坐标、属性和动作持有方则是[对象/动作组件体系](30_MetaAction派生类型与动作组件代码设计案.md)，两种“组件”通过承载和适配器衔接。

## 关键方法的声明与调用

| 实际声明类与方法 | 主要调用关系 | 职责 |
| --- | --- | --- |
| TilemapManager.RebuildMap / TryGetCell / TryScreenToCell | OnEnable 或外部重建；输入/能力查询 | 转换绘制层、读取地格、屏幕投影 |
| GridClickInput.ProcessPointer / SubmitScreenPoint / CancelPointer | Update 或语义调用 → 技能确认或 CellSelected | 设备阶段、点按确认和取消；先让技能适配器消费无指向确认，不改角色坐标 |
| GridClickInput.ProcessCancel | Update 检测右键 → 取消移动与技能选择 | 右键优先于同帧左键确认，退出两类选择 |
| CharacterMovementController.SelectMovement / CancelMovementSelection | 单位详情面板、输入或时间轴清理 | 保存当前机会/实例的选择，或清理指针、覆盖层与范围缓存；选择移动会取消技能选择 |
| CharacterMovementController.OnCellSelected / TryMoveToCell | 事件或调试入口 → 槽动作 ExecuteCell 或 ActionHolderComponent.TryExecute | 构造请求、检查控制权、映射结果 |
| CharacterMovementController.TryGetSelection | 输入/覆盖层 → 当前地格动作的 TryQueryTargets | 统一选格集合和版本来源，优先取已选中的槽内动作 |
| MovementCapability.TryGetTargets / Validate / TryMove | 实现 IMovementCapability；动作目标/效果组件调用 | 承载与实例有效性、范围校验、坐标生效 |
| MovementRange.Refresh / Contains / ClearSelectionCache | 目标查询、受理或取消选择 | 按查询计算范围、变化检测和清空；没有 LateUpdate 主动刷新 |
| MovementRangeOverlay.Show / UpdatePointerFeedback / Clear / Release | LateUpdate、禁用与销毁 | 覆盖层创建、反馈、清空与销毁 |
| SkillSelectionController.ProcessPointer / ExecuteCell | GridClickInput 与控制器 → 槽组件受理 | 无指向确认消费点击，地格指向把目的格交给槽内动作 |

MovementCapability 是 CharacterMovementController 内嵌套声明的类型，但接口方法仍声明在该嵌套类上；控制器的 TryMoveToCell 不等于接口的 TryMove。动作侧只见接口能力，不直接知道输入 MonoBehaviour 的字段。

## 移动选择的所有权与有效期

UnitDetailsPanel 的按钮调用控制器 SelectMovement。CanSelectMovement 判断控制器启用、动作定义有效，并在带时间轴时由 CanControl 核对当前角色与执行锁；它不等于完整地图/范围校验。选择移动会先取消技能适配器的槽选择，再记录机会编号和角色实例；重复选择仍有效的同一移动返回成功，不执行动作、不消耗机会，也不改变属性。

IsMovementSelected 还比较记录的机会和实例是否仍与当前一致；CanAcceptPlayerInput 则把两种地格选择都算作可接受输入：移动已选择，或技能适配器当前选中的槽是地格指向动作。TryGetSelection、IsSelectable 和选格事件因此受选择门槛保护；未选择时不查询目标、不显示范围。Update 发现原选择已失效就调用 CancelMovementSelection。

选择地格集合的来源会随选择变化：优先取技能适配器选中的地格动作，否则取移动持有组件的动作。二者都通过同一 `TryQueryTargets` 接口取得集合与版本，因此高亮和输入不需要区分是谁的动作。技能选择的完整流程见[技能槽专题](80_基础技能槽与待机动作代码设计案.md)。

CancelMovementSelection 同时清除选择标记与实例引用，调用输入 CancelPointer、覆盖层 Clear、范围 ClearSelectionCache。绑定时间轴、控制器禁用、移动成功、机会/实例失效以及右键会走这条清理路径；面板换行动者、重绑或禁用还会清理它记住的原控制器。绑定时间轴时还会把时间轴引用转给技能适配器。选择状态属于界面适配层，不是动作已进入 Executing 的证据。

公开的 TryMoveToCell 不检查 IsMovementSelected，调试或直接调用仍能在未选按钮时提交；它保留控制权、动作和能力的实际校验。存在选中的地格槽动作时，提交会改走槽组件的 `ExecuteCell`，成功后的清理同时覆盖移动选择与技能选择。不能把普通鼠标流程的按钮门槛误写成所有调用方共有的动作规则。

## 地图转换与派生范围

RebuildMap 先提升 Revision 并清空旧数据，要求绘制层属于当前 Grid、变换对齐、默认地形非空、映射无空项和重复，只接受 z=0 的二维格。已绘制瓦片转为记录，未映射时用默认地形，空洞和外部没有记录；失败清空并停止查询。绘制层变化后需显式重建，当前没有持续监听编辑变化。现有配置默认地形 ground、映射为空，没有把地形查询接成沼泽减速通知。

MovementRange.Refresh 读取行动力（术语表 T-036）当前值，取非负整数部分，遍历有限地图，筛选曼哈顿距离合格且不同于原格的地格，按 y 再 x 排序。缓存比较地图及 Revision、坐标/属性组件实例、原格与行动力；改变则重算并增加 Version。缺能力、禁用或行动力溢出会失效并清空范围。范围按目标查询或受理计算，ClearSelectionCache 在取消时置为未就绪并清空，不会自动于 LateUpdate 重建；下一次有效查询再生成。

当前没有路径搜索、阻挡、占格和累计地形成本；目标存在且距离合格即可成为可选格，中间有空洞也不会因路径不连通自动排除。范围是派生查询，不消耗属性中的行动力，也不保存到存档。

## 指针确认与动作协作

GridClickInput.Update 通过旧 Input 后端采集鼠标，右键按下先执行 ProcessCancel 并立即返回，不再处理同帧左键松开；取消同时作用于移动选择和技能槽选择。普通指针处理先把分阶段的按下/松开交给技能适配器：无指向的已选技能会在未被界面遮挡的位置按下并松开时被确认，并消费这次点击，不再派发选格意图。未被技能消费时，才即时检查调试面板遮挡和 GraphicRaycaster 界面命中，再将相机射线投影到 Grid 平面，仅允许当前地格动作的可选格进入按压。按下记录地格、范围版本和机会编号；离格、遮挡、失去可选性、范围或机会改变即取消本次按压，移回不恢复。原格松开才清除指针状态并派发一次 CellSelected；失焦、暂停、禁用输入清掉指针，但仅清指针不等于退出控制器中的移动选择。

SubmitScreenPoint 的 true 和 DispatchedCount 表示已派发意图，不表示完成移动。CharacterMovementController 订阅事件并在禁用时解除，记录目的格，要求角色当前可控，再把角色、目的格、机会、能力和时间轴放入 ActionExecutionContext，经当前选择的动作（槽动作或移动动作）进入受理。

能力校验要求承载活跃且已绑定、仍对应捕获的同一个运行实例、地图就绪、坐标绑定、属性存在，目的格在地图、不同原格且处于范围。移动效果调用 TryMove 时再次校验，再调用 SceneCoordinateComponent.MoveToCell；若生效中实例失效或坐标结果不符则抛异常，结束由[生命周期执行器](40_MetaActionLifecycle统一执行入口代码设计案.md)负责。待机没有地格目标，不经过上述能力校验。

控制器将动作结果映射成 Moved、AlreadyThere、NotReady、OutsideMap、OutOfRange、OutOfTurn 或 ActionRejected；正常指针已排除原格/范围外格，直接调用仍可收到这些拒绝。成功后取消移动选择与技能选择、清空范围，再通知时间轴控制器登记结果；实际回排已由生命周期完成。请求被拒绝而机会仍有效时不会自动退出选择。LastResult/LastError 可查询，当前没有统一弹窗呈现所有拒绝原因，也没有独立目的格预览后再按确认键的阶段或地图键盘/手柄输入映射。

## 高亮对象与清理

MovementRangeOverlay 从控制器的动作目标查询取得同一集合；未选择、不可控、查询失败或缺边框瓦片时清空。它在地图 Grid 下创建独立 Tilemap，不改原绘制层，按范围版本重绘；普通、悬停、按压分别为 0.5/0.8/1 透明度，再乘整体 tint，其 alpha 当前为 0.8。Clear 同时把 renderedVersion 设为 -1，重新选择时不会因旧版本号相同而留下空显示。

切换强调格先恢复旧格颜色，失去可选性撤掉强调。覆盖层使用承载渲染器共享材质，瓦片随 Grid 单元大小缩放；换 Grid 释放重建，禁用清空，销毁释放 Tilemap。三角色覆盖层均指向 MovementRangeTile，排序为 Front1/order 1，项目中存在 Front1。树预制体处于当前提交状态，最终遮挡和反馈观感未运行验证。
