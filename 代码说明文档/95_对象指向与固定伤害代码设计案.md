# 对象指向与固定伤害代码设计案

对象指向技能选择角色运行实例作为目标，报文保存目标 RuntimeId。固定伤害是当前已接入该指向性的效果：只允许指定射程内、具有 Health 量表的敌对对象，扣减配置的固定值并显示量表变化，成功后沿统一动作生命周期回排时间轴。

## 类型归属与职责

| 类型 | 继承或持有关系 | 实际职责 |
| --- | --- | --- |
| FixedDamagePacketBuilderDefinition | ActionPacketBuilderDefinition 派生 | 保存后摇引用、固定伤害值和射程，工厂创建独立运行构造器 |
| FixedDamagePacketBuilder | ActionPacketBuilder 派生；由 MetaActionInstance 持有 | 生成 FixedDamage 操作、Object 指向性、damage 与 range 参数 |
| ObjectTargeting | 静态规则类 | 按 FactionTag、Health 与曼哈顿射程形成目标资格结论，供查询和执行共同使用 |
| FixedDamageEffectExecutor | ActionEffectExecutor 派生；挂在 Router 同物体 | 解析来源与目标，调用量表 Modify，记录提交结果 |
| SkillSelectionController | 角色场景适配组件 | 保存槽位、机会与指针意图，查询参战目标，按同一对象按下并松开确认 |
| ObjectTargetOverlay | 角色场景适配组件，持有运行网格 Mesh | 接收范围与目标集合，绘制并集外轮廓和目标格填色；不判断敌我 |

对象组件、动作实例、统一生命周期与 Router 的基本关系沿用 10、30、40、90 专题。`MetaActionInstance.TargetRange` 来自当前构造器；`ActionExecutionContext.Target` 只携带目标运行实例，不持有其生命副本。

## 选择、提交与状态变化

底部第一个技能按钮或数字键 1 选择固定伤害技能。GridClickInput 仍负责统一采集指针；SkillSelectionController 对 Object 指向性将屏幕点投影到地格，从当前战斗参与者中选取该格的合法对象。友方和无目标位置不提交，右键取消不消耗行动机会；离开按下对象或失去选取条件会清除本次按压。

标准发送出口将对象的 RuntimeId 写入 `target`，同时登记来源与目标供 Router 解析。目标类型不同，`target` 编码也不同：Cell 是 `x,y` 字符串，None 不含此键，Object 是 RuntimeId。新增 Object 位于枚举末尾，既有 Cell/None 数字值保持不变。

FixedDamageEffectExecutor 通过 ObjectTargeting.Validate 取得当前目标结论，成功后调用 `MetaObjectMeterComponent.Modify(-damage)`；量表负责上下限钳位，UI 按当前量表值刷新。结果字段 `healthBefore`、`healthAfter`、`appliedDamage` 表达提交前值、提交后值与实际扣减量。执行器不自行推进时间轴；Succeeded 交给 MetaActionLifecycle 完成回排。

## 范围显示与资源生命周期

射程采用资产 range 的曼哈顿距离，显示集合只包含地图中存在的格子，与对象资格集合分别形成。ObjectTargetOverlay 遍历格子并集，只在相邻格子不属于集合时生成该边，内部公共边不会绘制。合法敌人所在格使用填色，悬停与按压提高不透明度；空地与友方格不填色。

叠加网格挂在地图 Grid 下，使用角色已有材质并在 Front1 层显示。取消、机会交接和组件禁用时隐藏；组件销毁时释放网格与运行物体。移动原有 Tilemap 范围表现保持独立。

## 资产与边界

`FixedDamageAction.asset` 配置伤害 25、射程 4，引用后摇 12 游戏秒的 `FixedDamageTiming.asset`。三个角色定义的第一个技能槽引用此动作，其余三个槽继续引用待机。PersistanceScene 的 Router 挂载固定伤害执行器，三个角色挂载对象范围显示组件。

本实现不读取力量或其他属性计算伤害，不加入伤害类型枚举、护甲、防护、治疗、死亡、持续效果或射线阻挡规则。生命归零仅由量表钳位表达，未自动移除单位或剥夺行动资格。对象查询限定本场战斗已装配参与者；同格多对象没有额外的候选切换界面，按参与者顺序取首个合法对象。

生命摘要与新增文案使用既有 UnitDetails 字体；补充固定伤害和范围提示所需字形，保留原字符、字体资产、材质与场景引用。主字体仍为静态 SDF。
