## 三、新增的 `I-` 条目编号与标题

续接本文件原有最大序号（原为 `I-INFO-10`），新增 8 条，编号连续、不跳号、不复用：

| 编号 | 标题（条目要点） |
| --- | --- |
| `I-INFO-11` | 不得重复实现引擎已提供的能力（对象池与集合池、异步任务、输入映射、音频与本地化与特效动画的播放原语、资产载体与序列化原语、资源加载、场景装卸与日志通道）；本系统只做「逻辑事件 → 资源、总线与动画状态」的解析与分轨对接，文案按标识取用 |
| `I-INFO-12` | 权威游戏状态由普通 C# 对象持有，引擎对象只承担承载、呈现与编辑器配置职责；不得把权威状态放在随场景销毁的对象上 |
| `I-INFO-13` | 不依赖引擎的启动回调顺序、脚本执行顺序或帧回调顺序满足初始化与推进的顺序要求；顺序由单元装配声明与显式调用序列决定 |
| `I-INFO-14` | 本单元在初始化时显式复位自身状态，不依赖引擎的域重载提供初始状态 |
| `I-INFO-15` | 影响游戏状态的判定不得使用帧时间；本作为半回合制，不设暂停概念，不得以暂停为由冻结数据或引入暂停语义 |
| `I-INFO-16` | 运行期配置的权威载体是引擎编辑器内的配置资产；设计库扩展配置表为初始素材与迁移来源，程序侧不直接读表、内容侧不直接改运行期资产 |
| `I-INFO-17` | 本系统不承担界面层级与界面清单；界面栈归 M08，全量界面清单权威来源为 `架构设计文档/界面索引.md` |
| `I-INFO-18` | 多语言在长期范围内不考虑，只预留接口，不在该方向过度设计 |

约定 §2.14 的第 6 项（空间判定归玩法侧、物理与动画只用于表现）适用于战斗与战场类文档，本单元不涉及，按「按需裁剪」未列入。
