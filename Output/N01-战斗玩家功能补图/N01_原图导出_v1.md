# 角色行为

## 角色技能
1. 制作元技能，以及相关组件约定
2. 设计一个挂机动作。并创建动作并列：轮到角色轮次时先选择要进行什么行动（放技能还是移动还是挂机），而不是默认进入角色移动的逻辑。并列为动作选择之一（依赖角色移动1）（元对象-技能容器组件）
3. 制作四种不同类型的基础技能 1. 对指定敌对目标造成固定值伤害 2. 向指定方向位移固定值距离 3. 对指定3x3地格范围内的单位造成伤害 4. 造成相当于目标10%总血量的伤害 四种技能分别对应：指定目标、指定范围、数值修正、位移 四个方向上的功能。需要构建四个或者以上数量的元技能组件来实现【概要】制作基础技能（依赖角色属性3）
4. 用边框描线描出可用攻击范围 用红色的高亮标记出范围伤害的作用范围 具体：点击选择技能，开启对这个技能的范围大小预览，所有可以被这个技能选中的地格（无视技能的目标选择规则，纯粹计算可选范围），用外框线描绘出来。此状态下按下右键取消对这个技能的选择，同时实现退出预览 当选中技能的时候，鼠标移动到地图上时，如果鼠标悬停的位置是可被技能选择的，则高亮标出会被技能影响的地格 以一个“投掷爆炸物”类型的技能为例，第一条显示的是投掷范围，第二条显示的是落点爆炸范围 单体近战类型技能为例：第一条显示攻击范围，第二条在鼠标悬浮在范围内的敌人身上时单独高亮敌人所在地格【概要】攻击技能效果预览
5. 每个角色单独保存一个行动槽，记录历史进行过的行动类型【概要】行动槽
6. 创建新的技能种类：连携技能 先不做继承效果，先完成消耗序列、释放效果、增加序列的循环【概要】连携技能
7. 当轮到自机角色轮次的时候： 1. 并列展示可选行动：移动、待机、基础技能、连携技能。这四项是并列层级，但是不要做多级展开，直接将“行动一项、待机一项、基础技能四项、连携技能五项”全部展示，UI设计上体现层级关系即可 2. 移动：单击之后，出现范围提示框，移动按钮高亮，高亮期间任意右键行为和对场景以外位置的左键退出高亮，鼠标悬浮在地格上预览角色移动位置，并根据移动距离渲染下一次行动时机预览，单击地格确认移动然后结束回合 3. 待机：鼠标悬浮在待机上的时候预览下一次角色行动时机，单击按下之后高亮按钮，这期间进行其他鼠标点击行为则退出高亮，再次单击则确认待机结束回合 4. 基础技能和连携技能：都是鼠标悬浮在技能按钮上显示范围，点击技能按钮高亮，高亮期间任意右键行为和对场景以外位置的左键退出高亮，然后鼠标在场景上悬浮以显示影响范围。非指向性技能和待机是一样的双击确认机制【概要】角色行为UI优化
8. 新条目【概要】技能继承效果

1. 平铺的地图绘制，每个瓦片无区别
2. 禁行地块，部分瓦片地图纹理笔刷设置禁止通过（依赖角色移动1）（TilemapManager）
3. 场景道具摆放。当部分场景道具摆放到地图上的时候，摆放位置自动设置不可移动，且设置多个角色不可处于同一格【概要】场景障碍物（元对象-角色标记组件，这个组件无功能，只作为将对象识别为角色的标记；元对象-地格占用组件，用于在本阶段阻止两个对象处于同一个地格，在未来阶段拓展开发多个对象共处一格的各式逻辑，核心功能是用标签数据记录对象以“何种方式”位于这个格子上，tilemapmanager会将这个组件当中的标签数据信息记录到地图信息中，以在地格参与各种逻辑判断时生效。采用 Prefab + 占用组件 + 自动生成地图占用数据 的方式实现地图障碍物布置。开发者通过拖拽预制体的方式在Tilemap场景中摆放对象，预制体自身携带占用规则组件，用于定义其占用地格数量和形状。编辑阶段，工具根据预制体的位置、碰撞范围和预设占用形状计算其影响的地格（这个计算过程由tilemapmanager负责），并生成对应的地图占用数据、运行时不再实时计算碰撞关系，而是直接读取已生成的占用信息，用于判断地格阻挡、路径寻路、交互检测等逻辑。碰撞体主要用于辅助编辑和自动生成占用区域，最终的地图占用关系由独立的占用数据管理。）
