```powershell
python -B -X utf8 'Output/N01-战斗玩家功能补图/N01_打开新图_v1.py' --no-browser --port 8793
```

随后打开 [本机新图](http://127.0.0.1:8793/)。服务只监听本机；按 Ctrl+C 停止。打开脚本复用现有工具，默认只读入本任务新库，编辑与默认 Markdown 导出均落在本任务目录。可选用 `PN_DB` 指向本任务目录内另一份已有副本库；脚本拒绝任务目录外的路径。

备份使用 SQLite 在线一致性备份，已重新只读载入核对。恢复时把该备份复制到新路径再用 `PN_DB` 打开，保留备份本身；本任务不向默认原图库执行恢复、导入、重置或替换。
