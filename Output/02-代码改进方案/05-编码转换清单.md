# 编码转换清单与脚本（5.4 落地）

> 现状（2026-09 实测）：24 个 .cs 中 **7 个为 GBK/ANSI**，其余 17 个为 **UTF-8 无 BOM**（报告中"部分带 BOM"的描述与实际不符，以本表实测为准）。
> 转换只改文件字节，**不触碰 .cs.meta，GUID 不变**，场景/资产/预制体引用全部不受影响。

## 2. PowerShell 脚本（Windows PowerShell 5.1 / 7 通用）

### 2.1 识别工程内非 UTF-8 的 .cs

```powershell
# 只读检测：输出 NOT-UTF8 的文件清单
Get-ChildItem 'D:\myspace\Git\mygame\Assets' -Recurse -Filter *.cs | ForEach-Object {
    try {
        $bytes = [System.IO.File]::ReadAllBytes($_.FullName)
        $enc = New-Object System.Text.UTF8Encoding($false, $true)   # throwOnInvalidBytes=true
        $null = $enc.GetString($bytes)
    } catch { Write-Output ('NOT-UTF8: ' + $_.FullName) }
}
```

### 2.2 执行转换（E-01：GBK(936) → UTF-8 带 BOM）

```powershell
$gbk = [System.Text.Encoding]::GetEncoding(936)
$utf8Bom = New-Object System.Text.UTF8Encoding($true)   # 带 BOM

$files = @(
    'Assets\Script\Inventory\Item\ItemFader.cs',
    'Assets\Script\Player\Player.cs',
    'Assets\Script\UI\SlotUI.cs',
    'Assets\Script\Utilities\DataCollection.cs',   # 若已按 F-11 删除，此行删除
    'Assets\Script\Utilities\Enums.cs',            # 若已按 F-09 删除，此行删除
    'Assets\Script\Utilities\Settings.cs',
    'Assets\Script\Utilities\SwitchBounds.cs'
)
foreach ($rel in $files) {
    $p = Join-Path 'D:\myspace\Git\mygame' $rel
    $text = [System.IO.File]::ReadAllText($p, $gbk)
    [System.IO.File]::WriteAllText($p, $text, $utf8Bom)
    Write-Output "converted: $rel"
}
```

### 2.3 可选（E-02：17 个 UTF-8 无 BOM 文件统一补 BOM）

```powershell
$utf8Bom = New-Object System.Text.UTF8Encoding($true)
$utf8NoBom = New-Object System.Text.UTF8Encoding($false)
Get-ChildItem 'D:\myspace\Git\mygame\Assets\Script','D:\myspace\Git\mygame\Assets\Editor' -Recurse -Filter *.cs | ForEach-Object {
    $bytes = [System.IO.File]::ReadAllBytes($_.FullName)
    if ($bytes.Length -ge 3 -and $bytes[0] -eq 0xEF -and $bytes[1] -eq 0xBB -and $bytes[2] -eq 0xBF) { return }  # 已有 BOM
    try {
        $enc = New-Object System.Text.UTF8Encoding($false, $true)
        $null = $enc.GetString($bytes)   # 非纯 UTF-8 的跳过（留给 E-01）
        $text = $utf8NoBom.GetString($bytes)
        [System.IO.File]::WriteAllText($_.FullName, $text, $utf8Bom)
        Write-Output "BOM added: $($_.FullName)"
    } catch { Write-Output "skip(GBK): $($_.FullName)" }
}
```

## 3. 验证

1. 转换后重新打开每个文件，中文注释与字符串无乱码（重点抽查原文件中的中文注释行）。
2. `git diff --stat` 应只显示 7（或 24）个 .cs；`git diff` 若 IDE 配置 UTF-8 则中文显示正常。
3. Unity 打开工程等待编译通过（编码不影响编译）。
4. 与"不要改动实现"约束的关系：本步骤是纯字节编码转换，git 历史上应**单独一个提交**，便于日后 diff 审查（报告 5.4 同款建议）。

## 4. 注意事项

- 转换前确保没有 IDE/Unity 正在写这些文件；完成后如 IDE 仍缓存旧编码，关闭重开。
- 若团队后续统一用 UTF-8 无 BOM（如 .editorconfig 设定），把 2.2 的 `$utf8Bom` 换成 `New-Object System.Text.UTF8Encoding($false)` 即可，其余不变——两种目标都可，关键是 7 个 GBK 文件必须脱离 GBK。
- `.meta` 文件全部不动。
