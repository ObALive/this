## 1. 节点目标与本次增量

节点正文：通过场景纹理组件与场景坐标组件将预置元对象显示在指定地图格子，渲染位置与其坐标一致。

节点声明对象：

- 元对象-场景纹理组件：保存角色渲染在场景上的纹理；获取脚本挂载物体上的 SpriteRenderer，把保存的纹理路径对应的纹理赋值到该组件。
- 元对象-场景坐标组件：确认对象渲染位置，把对象锚点渲染在地图网格的格子中心。

本次增量建立元对象运行时形态、组件约定，并把两个场景组件直接接到工程已有的 `Player` 与 `01.Field` 上；不实现后续的点击移动、寻路、移动动画，也不实现完整的对象与组件注册表。

## 2. 运行时结构

| 类型 | 职责 | 关键约定 |
| --- | --- | --- |
| `IMetaObjectComponent` | 元对象组件最小标记 | 任何可挂载到元对象实例的组件都实现此接口 |
| `MetaObjectComponent` | 组件的生命周期基类 | `Attach` → `Bind` → `Unbind`；组件是普通 C# 对象，场景引用只为表现服务 |
| `MetaObjectInstance` | 元对象运行时实例 | 以具体组件类型为键保存组件构成；`MetaObjectId` 可被物品等派生类型覆盖 |
| `MetaObjectComponentDefinition` | 组件配置项基类 | 只负责创建运行时组件，不持有运行时状态 |
| `MetaObjectDefinition` | 元对象定义资产 | 元对象标识、显示名、`[SerializeReference]` 组件配置清单；`CreateInstance()` 创建实例 |
| `SceneTextureComponent` | 元对象-场景纹理组件 | 保存 `TexturePath` 与可选直接 `Sprite`；绑定时赋给 `SpriteRenderer`；失败时记录错误且不写入空纹理 |
| `SceneCoordinateComponent` | 元对象-场景坐标组件 | 保存 `Vector2Int Cell` 与可选 `AnchorOffset`；绑定/改格时把对象根节点放到 `Grid.GetCellCenterWorld(cell)` |
| `MetaObjectPreset` | 预置元对象的场景承载 | 按定义创建实例，补坐标组件，绑定纹理与坐标；支持从当前世界坐标换算格子，并等待地图 Grid 加载 |

## 3. 现有工程上的实际接线

### 3.1 PersistanceScene / Player

- 在现有 `Player` 根节点（`PersistanceScene`）上新增 `MetaObjectPreset`；
- `definition` 指向 `Assets/GameData/MetaObjects/Player.asset`；
- `cell` 由 `useCurrentCellOnAwake` 在找到地图 Grid 后从 Player 当前世界坐标换算；
- `grid` 不在编辑期硬绑定，运行时由 `FindObjectOfType<Grid>()` 找到 `01.Field` 的 Grid；
- `Player` 的 WASD 组件（`Player.cs`）在场景中设为 `m_Enabled: 0`，脚本与字段保留，可随时重新启用；节点不保留 WASD 移动；
- Player 的多层 SpriteRenderer、SortingGroup、Collider2D、Rigidbody2D 未改动。

### 3.2 元对象定义

`Assets/GameData/MetaObjects/Player.asset`：

- `metaObjectId = CHAR_PLAYER`，`displayName = 玩家角色`；
- 组件 1：`SceneTextureComponentDefinition`

### 3.3 地图

- 使用现有 `Assets/Scenes/01.Field.unity` 的 Grid（cellSize 1×1）；
- 运行时 Grid 与 Player 分属两个场景，`MetaObjectPreset` 支持通过 `SceneManager.sceneLoaded` 等待地图加载后再绑定；本次 Play Mode 验证时两个场景均已打开，未单独构造“先 Player、后地图”的晚加载时序；

`SceneTextureComponent` 保留 Resources 路径契约；同时允许配置直接 `Sprite`，用于工程内已有的美术资源，避免为了路径契约复制一份 Body Sprite。`Player.asset` 使用直接 Body Sprite；`Assets/Resources/MetaObjects/Characters/PlayerDemo.png` 仅作为 `LoadSprite` 正路径的测试夹具保留。

## 4. 验证与结果

### 4.1 编译

- 使用运行中的 Unity 2022.3.62f3c1 编辑器与 Unity MCP 执行刷新/编译；
- 最终 Console 错误数为 0；
- 过程中修复过 `TextureImporter.spriteAlignment` 不可用的问题（改用 `TextureImporterSettings`）。

### 4.2 编辑器内行为验证

执行 `MetaObjectVerification.VerifyAll()`，结果为 `PASS`。覆盖：

- 玩家定义资产可创建实例，实例包含场景纹理组件与场景坐标组件；
- 场景纹理组件直接引用 `BodyWalkDown_0` 的 Sprite，并保存纹理路径；
- Resources 正路径加载成功，不存在路径与空路径返回 `null`；
- `ItemInstance` 作为 `MetaObjectInstance` 派生类型仍能创建、挂载、取回、移除物品组件；
- 在 `PersistanceScene + 01.Field` 中，Player 的 `MetaObjectPreset` 找到 Grid，按当前位置换算格子 `(7,-4)`，并吸附到格子中心 `(7.5,-3.5)`；
- Player 的 Body 渲染器使用了纹理组件解析出的 Sprite；
- Player 的 WASD 组件处于停用状态。

结果文件：`Logs/metaobject_verification_result.txt`，内容为 `PASS`。

## 5. 后续节点可直接使用的入口

- `MetaObjectPreset.TryBindToGrid()`：等待并绑定地图 Grid，按当前位置取格；
- `MetaObjectPreset.SetCell(Vector2Int)`：更新格子并同步场景位置；
- `MetaObjectPreset.Instance`：取得当前元对象实例；
- `SceneCoordinateComponent.Cell / SetCell / TryGetWorldPosition`：格子坐标与格子中心换算；
- `SceneTextureComponent.AssignedSprite / ResolvedSprite / LoadSprite(path)`：纹理来源与解析；
- `MetaObjectDefinition.CreateInstance()`、`MetaObjectInstance.AddComponent/GetComponent/RemoveComponent`：元对象构成管理。
