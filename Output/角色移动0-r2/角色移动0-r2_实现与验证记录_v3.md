## 1 完成的可观察能力

在工程现有的 `PersistanceScene/Player` 上建立了一个预置元对象：

- `Player` 根节点挂 `MetaObjectPreset`，定义资产为 `Assets/GameData/MetaObjects/Player.asset`（`CHAR_PLAYER`，显示名“玩家角色”），组件构成为 `SceneTextureComponent` 与 `SceneCoordinateComponent` 各一个；
- 预置的初始格子由物体在场景中的摆放位置换算（Player 位于 `(7.91,-3.78)`，换算为格子 `(7,-4)`），绑定后锚点落在格子中心 `(7.5,-3.5,0)`；
- 场景纹理组件把定义中的纹理赋给 `BodyWalkDown_0` 渲染器；
- **运行期改动只走组件方法**：`SceneCoordinateComponent.SetCell` 立即改位置，`SceneTextureComponent.SetTexture` / `SetTexturePath` 立即改显示；
- Debug Panel 的“元对象”面板可在 Play Mode 直接验证：输入格子并应用、方向键逐格移动、切换纹理、回到初始格子，面板实时显示当前格子、位置与纹理。

## 2 运行时结构与约定

### 2.1 静态定义与运行时实例分离

| 类型 | 角色 | 位置 |
| --- | --- | --- |
| `MetaObjectDefinition` | 静态定义（ScriptableObject）：`MetaObjectId`、`DisplayName`、`[SerializeReference]` 组件配置清单；`CreateInstance()` 按清单建实例 | `Assets/Script/MetaObjects/MetaObjectDefinition.cs` |
| `MetaObjectComponentDefinition` | 组件配置项基类，只创建运行时组件，不持有运行时状态 | `MetaObjectComponentDefinition.cs` |
| `MetaObjectInstance` | 运行时实例：`MetaObjectId` + `Dictionary<具体组件类型, MetaObjectComponent>` | `MetaObjectInstance.cs` |
| `MetaObjectComponent` | 组件基类与生命周期约定 | `MetaObjectComponent.cs` |
| `MetaObjectPreset` | 场景承载：建实例、绑定场景、把玩法侧的格子调用转发给坐标组件 | `MetaObjectPreset.cs` |

定义与实例严格分离：定义是编辑器资产、运行期只读；实例是运行时对象。实例不承担存档形态（存档按后续节点的判别字段式多态序列化接入）。

### 2.2 组件生命周期（组件约定）

`MetaObjectComponent` 提供四个可重写的受保护方法，顺序固定：

```
OnAttached  -> 加入 MetaObjectInstance，Owner 可用
OnBind      -> 绑定到 MetaObjectPreset，Preset 可用，才允许访问场景对象
OnUnbind    -> 离开场景承载，不得再访问场景
OnDetached  -> 离开实例，释放组件自己持有的资源
```

实例侧入口：`AddComponent`（同具体类型重复挂载时替换并先 `Detach` 旧组件）、`RemoveComponent<T>`、`UnbindAll`、`Dispose`。
组件不继承 `MonoBehaviour`，不自行查找场景对象；场景侧引用统一由 `MetaObjectPreset` 提供。

### 2.3 关键状态私有，只经方法改动

| 组件 | 私有关键状态 | 唯一改动入口 | 改动方法内的效果应用 |
| --- | --- | --- | --- |
| `SceneCoordinateComponent` | `private Vector2Int cell` | `SetCell(Vector2Int)` | 立即调用 `ApplyToScene()`：按 `Preset.MapGrid` 算格子中心，写 `preset.transform.position` |
| `SceneTextureComponent` | `private Sprite texture`、`private string texturePath` | `SetTexture(Sprite)`、`SetTexturePath(string)` | 立即调用 `ApplyToScene()`：把 `texture` 写到 `Preset.Renderer.sprite` |

对外只暴露只读属性：`SceneCoordinateComponent.Cell`、`SceneTextureComponent.Texture`、`SceneTextureComponent.TexturePath`。
非法改动被拒绝并保留原状态：`SetTexture(null)` 返回 false；`SetTexturePath` 解析失败返回 false，原路径与原纹理不变。
`ApplyToScene()` 是公开的“重新应用当前状态”方法，不改变状态本身，供 Grid 变化或重新绑定时使用。

### 2.4 格子的来源与转发

预置不再序列化格子字段（场景中已无 `cell`、`adoptCurrentCellOnAwake`）：

- **初始格子**：绑定时按物体在场景中的摆放位置 `Grid.WorldToCell(transform.position)` 换算；
- **绑定前赋值**：`MetaObjectPreset.SetCell` 在实例未建立时暂存，绑定后交给坐标组件初始化；
- **运行期改动**：`MetaObjectPreset.SetCell` 转发 `SceneCoordinateComponent.SetCell`；组件写完私有坐标后立即应用；
- **重新应用**：`MetaObjectPreset.BindGrid` 在 Grid 变化后调用 `SceneCoordinateComponent.ApplyToScene()`；
- 预置本身没有 Update 轮询，也不监听任何字段变化。

### 2.5 场景解析顺序

- **Grid**：显式 `grid` → 父级 Grid → 预置所在场景内的 Grid → `gridSceneName` 指定场景（默认 `01.Field`）内的 Grid → 仅当全图只有一个 Grid 时采用它。多个 Grid 且未命中时不猜，记录错误并保持挂起。
- **Renderer**：显式 `spriteRenderer` → 本物体 `SpriteRenderer` → 子物体第一个 `SpriteRenderer`。
- **晚加载**：带场景坐标组件的预置在没有 Grid 时保持挂起，在 `Start` 与 `SceneManager.sceneLoaded` 时重试；`BindGrid(Grid)` 供地图加载侧显式提供 Grid。

## 4 关键决定与理由

1. **关键状态放在组件里**：节点声明把坐标与纹理归到两个组件。格子属于坐标组件、纹理属于纹理组件，预置只做承载与转发，避免预置与组件各存一份。
2. **只经方法改动**：两个组件把状态设为 `private`，对外只给 `SetCell` / `SetTexture` / `SetTexturePath`。效果应用放在方法内部，调用方不需要“先改值再手动刷新”，也不会出现“值变了但场景没变”。
3. **不监听字段变化**：预置不再有格子字段，也不做 Update 轮询；初始格子由场景摆放位置换算，运行期改动必须经过方法。这样不存在“改 Inspector 字段但没用”的隐性入口。
4. **Debug Panel 作为验收入口**：面板只调用组件方法，和游戏代码同一条路径；输入格子、方向键、切换纹理、回到初始格子足以覆盖两个关键状态。
5. **关掉 WASD `Player` 组件**：WASD 直接改 `transform` 而不更新格子，会与格子权威冲突；保留脚本与字段，只把场景中的组件停用，后续“点击地格移动”节点接管格子写入后再决定去留。
6. **纹理同时支持路径与直接 Sprite**：现有美术在 `Assets/M Studio/...`，不在 Resources；直接 Sprite 保证当前显示，`texturePath` 保留来源契约；非 Resources 路径在编辑器内可解析，打包运行需改走 Resources 或资源服务。
7. **不在本节点铺开注册表**：设计案的 `CLS-OBJ-001` 至 `CLS-OBJ-009`、`API-OBJ-001` 至 `API-OBJ-005` 包含注册表、实体类型登记、能力类别与挂载契约。本节点只建立运行时约定与两个组件；注册表留给组件族扩展前落地。
8. **不改动物品侧既有模型**：现有 `ItemInstance` / `ItemComponent` 有自己的组件字典，本节点不迁移，避免把物品系统卷入。

## 6 下游可直接使用的入口

```csharp
MetaObjectPreset preset = player.GetComponent<MetaObjectPreset>();
MetaObjectInstance instance = preset.Instance;
SceneCoordinateComponent coordinate = instance.GetComponent<SceneCoordinateComponent>();
SceneTextureComponent texture = instance.GetComponent<SceneTextureComponent>();

// 改格子：预置转发给坐标组件，组件写完私有坐标后立即移动到格子中心
preset.SetCell(new Vector2Int(7, -3));

// 也可以直接经组件改动（推荐在只持有组件的代码里使用）
coordinate.SetCell(new Vector2Int(7, -3));
Vector2Int cell = coordinate.Cell;                  // 只读
coordinate.ApplyToScene();                          // Grid 变化后重新应用，不改坐标

// 改纹理：组件写完私有纹理后立即写到场景渲染器
texture.SetTexture(someSprite);
bool ok = texture.SetTexturePath("Assets/.../BodyWalkDown.png");
Sprite current = texture.Texture;                   // 只读
string source = texture.TexturePath;                // 只读

// 地图加载后显式提供 Grid
preset.BindGrid(mapGrid);

// 查询对象锚点应处的世界坐标
Vector3 world;
bool ok2 = preset.TryGetCellWorldPosition(out world);
```

`MetaObjectPreset` 的公开状态：`Definition`、`Instance`、`Cell`（只读）、`IsBound`、`IsPendingBinding`、`MapGrid`、`Renderer`；公开方法：`TryBind()`、`Rebuild()`、`SetCell(Vector2Int)`、`BindGrid(Grid)`、`TryGetCellWorldPosition(out Vector3)`。
