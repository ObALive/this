## 2 运行时结构与组件约定

| 类型 | 角色 | 位置 |
| --- | --- | --- |
| `MetaObjectDefinition` | 静态定义（ScriptableObject）：`MetaObjectId`、`DisplayName`、`[SerializeReference]` 组件配置 | `Assets/Script/MetaObjects/MetaObjectDefinition.cs` |
| `MetaObjectComponentDefinition` | 组件配置项基类，只创建运行时组件 | `MetaObjectComponentDefinition.cs` |
| `MetaObjectInstance` | 运行时实例：`MetaObjectId` + `Dictionary<具体组件类型, MetaObjectComponent>` | `MetaObjectInstance.cs` |
| `MetaObjectComponent` | 组件基类与生命周期约定 | `MetaObjectComponent.cs` |
| `MetaObjectPreset` | 场景承载：建实例、绑定场景、把格子调用转发给坐标组件 | `MetaObjectPreset.cs` |

组件生命周期：`OnAttached → OnBind → OnUnbind → OnDetached`。组件不继承 `MonoBehaviour`，不自行查找场景对象，场景引用由 `MetaObjectPreset` 提供。

关键状态私有，只经方法改动：

| 组件 | 私有状态 | 唯一入口 | 方法内应用 |
| --- | --- | --- | --- |
| `SceneCoordinateComponent` | `private Vector2Int cell` | `SetCell(Vector2Int)` | `ApplyToScene()`：按 `Preset.MapGrid` 把锚点写到格子中心 |
| `SceneTextureComponent` | `private Sprite texture`、`private string texturePath` | `SetTexture(Sprite)`、`SetTexturePath(string)` | `ApplyToScene()`：把纹理写到 `Preset.Renderer.sprite` |

- `SetTexture(null)` 返回 false 并保留原纹理；`SetTexturePath` 解析失败返回 false，原路径与原纹理不变。
- 纹理未配置（`texture == null` 且 `texturePath` 为空）是合法状态：不报错、不清空渲染器，等待赋值。
- 预置没有格子字段、不监听字段变化；初始格子由物体在场景中的摆放位置换算。绑定前调用 `SetCell` 会暂存。

## 4 关键决定

1. **多对象角色存预制体撤下**：现有渲染逻辑是“一个元对象一个 SpriteRenderer”，四个子渲染器无法由场景纹理组件正确表达。把整棵角色树保存为预制体保留可恢复性，场景换成单一空对象。
2. **占位角色只挂必要组件**：`SpriteRenderer` 供纹理组件写入，`MetaObjectPreset` 负责元对象实例与格子定位；碰撞、刚体、WASD、拾取、淡出都属于被撤下的角色预制体，不在本节点占位对象上保留。
3. **纹理留空**：定义里的 `texturePath` 与 `sprite` 都为空，由用户在 `Player.asset` 的 `SceneTextureComponentDefinition` 里赋值。组件把“未配置”与“配置了路径但解析失败”分开处理：前者静默，后者报错。
4. **相机引用重接**：删除旧 Player 前把 `m_Follow`、`m_LookAt` 转到新 Player，避免相机失去跟随目标。
5. **关键状态只经方法改动**：坐标与纹理为组件私有状态，`SetCell` / `SetTexture` / `SetTexturePath` 内完成效果应用；预置不做字段监听。
6. **Debug Panel 验收**：格子输入 + 应用、方向键、切换纹理、回到初始格子；纹理未赋值时“切换纹理”没有候选，赋值后可用于切换。

## 6 下游入口

```csharp
MetaObjectPreset preset = player.GetComponent<MetaObjectPreset>();
SceneCoordinateComponent coordinate = preset.Instance.GetComponent<SceneCoordinateComponent>();
SceneTextureComponent texture = preset.Instance.GetComponent<SceneTextureComponent>();

preset.SetCell(new Vector2Int(7, -3));   // 改格子并立即移动
coordinate.SetCell(new Vector2Int(7, -3));
coordinate.ApplyToScene();               // Grid 变化后重新应用

texture.SetTexture(someSprite);          // 改纹理并立即写入 SpriteRenderer
texture.SetTexturePath("Assets/.../x.png");

preset.BindGrid(mapGrid);                // 地图加载后显式提供 Grid
```
