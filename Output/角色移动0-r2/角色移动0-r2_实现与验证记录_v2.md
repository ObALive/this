## 1 完成的可观察能力

在工程现有的 `PersistanceScene/Player` 上建立了一个预置元对象：

- `Player` 根节点挂 `MetaObjectPreset`，定义资产为 `Assets/GameData/MetaObjects/Player.asset`（`CHAR_PLAYER`，显示名“玩家角色”），组件构成为 `SceneTextureComponent` 与 `SceneCoordinateComponent` 各一个；
- 预置格子在场景中序列化为 `(7, -4)`，运行时按 `01.Field/Grid` 的格子中心把对象锚点放到 `(7.5, -3.5, 0)`；
- 场景纹理组件把定义中记录的纹理赋给 `BodyWalkDown_0` 渲染器；
- **运行期修改格子即移动**：直接改 `cell` 序列化字段（Inspector / 调试器 / 反射）、代码设置 `preset.Cell`、或调用 `preset.SetCell(...)`，对象都会移动到新格子中心。

## 2 运行时结构与约定

### 2.1 静态定义与运行时实例分离

| 类型 | 角色 | 位置 |
| --- | --- | --- |
| `MetaObjectDefinition` | 静态定义（ScriptableObject）：`MetaObjectId`、`DisplayName`、`[SerializeReference]` 组件配置清单；`CreateInstance()` 按清单建实例 | `Assets/Script/MetaObjects/MetaObjectDefinition.cs` |
| `MetaObjectComponentDefinition` | 组件配置项基类，只创建运行时组件，不持有运行时状态 | `MetaObjectComponentDefinition.cs` |
| `MetaObjectInstance` | 运行时实例：`MetaObjectId` + `Dictionary<具体组件类型, MetaObjectComponent>` | `MetaObjectInstance.cs` |
| `MetaObjectComponent` | 组件基类与生命周期约定 | `MetaObjectComponent.cs` |
| `MetaObjectPreset` | 场景承载：建实例、绑定场景、按格子定位、监听格子变化 | `MetaObjectPreset.cs` |

定义与实例严格分离：定义是编辑器资产、运行期只读；实例是运行时对象。实例不承担存档形态（存档按后续节点的判别字段式多态序列化接入）。

### 2.2 组件生命周期（组件约定）

`MetaObjectComponent` 提供四个可重写的受保护方法，顺序固定：

```
OnAttached  -> 加入 MetaObjectInstance，Owner 可用
OnBind      -> 绑定到 MetaObjectPreset，Preset 可用，才允许访问场景对象
OnUnbind    -> 离开场景承载，不得再访问场景
OnDetached  -> 离开实例，释放组件自己持有的资源
```

实例侧入口：`AddComponent`（同具体类型重复挂载时替换并先 `Detach` 旧组件）、`RemoveComponent<T>`、`UnbindAll`、`Dispose`。
组件不继承 `MonoBehaviour`，不自行查找场景对象；场景侧引用统一由 `MetaObjectPreset` 提供，避免组件各自持有场景耦合。

### 2.3 两个已实现组件

| 组件 | 配置项 | 运行时职责 | 失败口径 |
| --- | --- | --- | --- |
| `SceneTextureComponent` | `texturePath`（工程路径或 Resources 相对路径）、可选 `sprite` | 绑定场景时把可用 Sprite 赋给 `MetaObjectPreset.Renderer` | 找不到渲染器或纹理无法解析时记录错误并保留渲染器原有显示，不写入空纹理 |
| `SceneCoordinateComponent` | `anchorOffset`（格子中心之上的世界偏移） | 按 `MetaObjectPreset.Cell` 与地图 Grid 计算格子中心，把对象锚点（`transform.position`）放到该处 | Grid 为空时记录错误且不移动对象 |

格子坐标属于场景摆放，只存在于预置（`MetaObjectPreset.cell`），不写进共享定义；坐标组件在绑定与 `SetCell` 时读取它。

### 2.4 格子的两个入口与字段同步

`MetaObjectPreset` 的格子有两个入口，最终都落到 `ApplyCell()`：

- `SetCell(Vector2Int)` 或 `Cell` 属性赋值：立即写字段并应用；
- 直接改 `cell` 序列化字段（Inspector、调试器、反射）：`Update()` 比较字段值与 `appliedCell`，不一致时在下一帧补一次应用。

`appliedCell` 记录最近一次真正写入坐标组件的格子；`TryBind` 成功后同步它。字段值未变化时每帧只做一次 `Vector2Int` 比较，不写场景。未绑定或等待 Grid 时只保留字段值，绑定成功后由 `TryBind` 按最新值定位。

### 2.5 场景解析顺序

- **Grid**：显式 `grid` → 父级 Grid → 预置所在场景内的 Grid → `gridSceneName` 指定场景（默认 `01.Field`）内的 Grid → 仅当全图只有一个 Grid 时采用它。多个 Grid 且未命中时不猜，记录错误并保持挂起。
- **Renderer**：显式 `spriteRenderer` → 本物体 `SpriteRenderer` → 子物体第一个 `SpriteRenderer`。
- **晚加载**：带场景坐标组件的预置在没有 Grid 时保持挂起，在 `Start` 与 `SceneManager.sceneLoaded` 时重试；`BindGrid(Grid)` 供地图加载侧显式提供 Grid。

## 4 关键决定与理由

1. **格子不是定义的一部分**：同一个定义可以被多个预置复用，格子随摆放变化，因此放在 `MetaObjectPreset`，坐标组件读取它。避免“定义里的格子”和“场景里的格子”两个事实来源。
2. **字段即权威，Update 补应用**：验收明确要求“运行时修改 cell 变量”就移动。Inspector 改字段不会调用任何方法，因此不能只提供 `SetCell`；用 `Update` 比较字段与已应用值，覆盖 Inspector、调试器、反射三种改法，代价是每帧一次整数比较。
3. **关掉 WASD `Player` 组件**：本节点的可观察条件是“渲染位置与其坐标一致”。WASD 直接改 `transform` 而不更新格子，会与格子权威冲突；保留脚本与字段，只把场景中的组件停用，后续“点击地格移动”节点接管格子写入后再决定去留。
4. **纹理同时支持路径与直接 Sprite**：节点声明要求“保存纹理路径并把对应纹理赋给渲染器”，但现有美术在 `Assets/M Studio/...`，不在 Resources。直接 Sprite 保证当前显示，`texturePath` 保留来源契约；非 Resources 路径在编辑器内可解析，打包运行需改走 Resources 或资源服务（见限制）。
5. **不在本节点铺开注册表**：`Code_Design/01-通用系统/30_元对象与组件代码设计案.md` 的 `CLS-OBJ-001` 至 `CLS-OBJ-009`、`API-OBJ-001` 至 `API-OBJ-005` 包含注册表、实体类型登记、能力类别与挂载契约。本节点只建立运行时约定与两个组件；注册表与登记校验留给组件族扩展前落地，避免半套注册表。
6. **不改动物品侧既有模型**：现有 `ItemInstance` / `ItemComponent` 有自己的组件字典。本节点不把它迁移到 `MetaObjectInstance`，避免把物品系统卷入并造成回归；统一应在物品侧节点按设计案单独做。

## 6 下游可直接使用的入口

```csharp
MetaObjectPreset preset = player.GetComponent<MetaObjectPreset>();
MetaObjectInstance instance = preset.Instance;
SceneCoordinateComponent coordinate = instance.GetComponent<SceneCoordinateComponent>();
SceneTextureComponent texture = instance.GetComponent<SceneTextureComponent>();

// 写格子：两种等价写法，立即把锚点吸附到格子中心
preset.SetCell(new Vector2Int(7, -3));
preset.Cell = new Vector2Int(7, -3);

// 直接改序列化字段（Inspector / 调试器）也会在下一帧应用
// preset 的 cell 字段（Inspector 中显示为 Cell）

// 地图加载后显式提供 Grid（可选，优先于场景名解析）
preset.BindGrid(mapGrid);

// 查询对象锚点应处的世界坐标
Vector3 world;
bool ok = preset.TryGetCellWorldPosition(out world);

// 组件查找与构成
bool has = instance.HasComponent<SceneCoordinateComponent>();
instance.TryGetComponent<SceneCoordinateComponent>(out coordinate);
```

`MetaObjectPreset` 的公开状态：`Definition`、`Instance`、`Cell`（可读可写）、`IsBound`、`IsPendingBinding`、`MapGrid`、`Renderer`；公开方法：`TryBind()`、`Rebuild()`、`SetCell(Vector2Int)`、`BindGrid(Grid)`、`TryGetCellWorldPosition(out Vector3)`。
