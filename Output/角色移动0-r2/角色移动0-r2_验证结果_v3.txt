一、本版改动
1. 移除 v2 的序列化字段变化监听（MetaObjectPreset.Update + appliedCell）与预置上的 cell 字段。
2. 关键状态改为组件私有，只能经组件方法改动：
   - SceneCoordinateComponent：private Vector2Int cell；唯一入口 SetCell(Vector2Int)；
     SetCell 内直接调用 ApplyToScene()，把锚点移动到格子中心。
   - SceneTextureComponent：private Sprite texture、private string texturePath；
     唯一入口 SetTexture(Sprite) 与 SetTexturePath(string)；两者内部直接调用 ApplyToScene()，
     把纹理写到场景 SpriteRenderer。
3. 预置只做转发与承载：MetaObjectPreset.SetCell 转发给坐标组件的 SetCell；
   初始格子改为按物体在场景中的摆放位置换算（不再有可编辑的 cell 字段），
   绑定前调用 SetCell 会暂存，绑定后按暂存值初始化。
4. 验收入口：DebugPanel 增加“元对象”面板，显示元对象标识、格子、位置、纹理，
   提供格子输入 + 应用、← → ↑ ↓、切换纹理、回到初始格子；所有按钮都调用上述组件方法。
