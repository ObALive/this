## 一、关于字母：包装解决表达，不解决结构

**回应总监**：ABCD 是创意初稿占位符，后续以词汇与图标（轻击、重击等）替换——完全合理，我此前评价中"字母抽象"的批评在包装层面被正确回应，予以收回。

但需要区分我原批评的两个层面：

1. **表达层（已解决）**：符号抽象、无主题。→ 词汇与图标包装可解决。
2. **结构层（仍待定）**：成本串匹配 + 队列挤出 + M 打断 + 效果继承，四层规则叠加的认知负荷，与符号无关。→ 包装不改变结构，需要设计决策（见下文建议）。

**本环节最重要的建议——让包装词汇同时服务两个子系统。**

创意文档战斗章存在两套并行的规则：行动槽（字母序列，§10.5）与时间轴（行动轻重决定下次行动时机，§10.2）。两者目前使用**两套词汇**：前者是抽象字母，后者是"轻重"。这恰是包装阶段可以一举消除"认知孤岛"的机会：

**类别映射示例（供文案阶段参考，非定案）**

| 类别 | 词汇      | 行动槽角色                | 时间轴角色        |
| ---- | --------- | ------------------------- | ----------------- |
| A    | 轻击      | 连携序列中的"快节奏音符"  | 后摇短 → 下回合快 |
| B    | 重击      | 连携序列中的"重音/破防音" | 后摇长 → 下回合慢 |
| C    | 架势/防守 | 蓄力、格挡类              | 后摇中 → 稳定节奏 |
| D    | 射击/远程 | 牵制、先手类              | 后摇中            |
| M    | 走位      | 打断连携                  | 小代价位移        |

于是玩家对"字母串"的理解与对"时间轴"的理解共用同一套"轻重节奏"心智模型：**轻击快了重击慢、重击打出的破绽被轻击收割**。连携命名随之自然化——"轻轻重"即"破绽三连"，成本串不再是拼词，而是招路。

配套结构建议（相对评价书 4.6 的更新）：

- 首版成本串长度上限 3（精英连携可放宽），连携数量 5 保留；
- 战斗 UI"点亮即示"：槽尾序列逐位对照各连携成本串，差一步时高亮提示下一步该出什么，让新手"跟着光完成连招"，高手"预排整条序列"；
- 移动建议仍只中断连携、不参与序列（M 不入槽），降低队列推理负担——此点在词汇包装后可以再评估，但首版从简。

## 二、关于战斗为核心：认同方向，但深度的投资方式需要辨析

**认同**：哈迪斯、杀戮尖塔、以撒的战斗确实是各自游戏的核心，且肉鸽的耐玩性来自随机环境中的战斗深度。本作把战斗作为"资源即战力"（§3.3）的最终出口——经营、日程、情报的全部决策最终在战斗中兑现——因此**战斗值得成为深度投资对象，这个判断我完全支持**，并修正评价书中的相关保留意见。

**但有一处关键辨析**：那三款作品是"纯战斗"游戏，其全部复杂度预算都花在战斗上（以撒的一切系统都是为战斗服务的道具，尖塔的整局就是战斗+为战斗的构筑）。本作是三支柱游戏——日程机会成本、经营情报、战斗。深度投资的方向因此不应是"机制数量"，而应是**交互密度**：肉鸽深度的性价比公式是"系统之间交互 × 随机环境方差"，而非"单系统规则数量"。

这个辨析恰好说明：总监的增量思路（装备/遗物/技能库存联动）与"深度战斗"的正确打开方式完全一致——**用经营系统去加深战斗，而不是在战斗内部堆新规则**。详见第三节。

**关于"搓招 × 战棋"融合的新颖性评估——认同有开发潜质，但需诚实地重新命名。**

即时动作搓招的体感由三要素构成：

| 要素 | 动作游戏中    | 本作（半回合战棋）的对应移植                        | 可行性                   |
| ---- | ------------- | --------------------------------------------------- | ------------------------ |
| 执行 | 肌肉记忆/手速 | 无法移植，也不应移植（本作是决策游戏）              | 放弃，且放弃得理直气壮   |
| 时机 | 出招窗口      | 时间轴：轻重后摇决定节奏，连携完成的"节奏奖励"      | 可移植，是融合的主战场   |
| 风险 | 连段被打断    | 敌方时间轴插队"破招"打断你的序列；走位打断（§10.5） | 可移植，是融合的核心张力 |

结论：本作的"搓招"实际是**"排招"——不需要手速的决策式连招**。这个定位本身就是卖点（对策略玩家），但**市场表达上不要用"搓招"一词**，否则动作玩家会因"没有执行感"而失望。建议宣传语向"计划连招/决策连招"靠拢。

**三个具体融合机制建议（供纲要阶段立项）：**

1. **读招敌人**：敌方 AI 会"记住/针对"你的出招类型（如重击型敌人架开重击、敏捷型敌人闪避连续轻击），情报系统（§10.7）告知玩家敌人会破什么招。于是"连携选择"升级为"战术读招"——这正是战棋决策的一半，且与情报支柱深度耦合。
2. **节奏奖励**：完成一条完整连携后，时间轴给予奖励（下次行动提前若干刻度）。效果是：重击慢、连携快，"轻-轻-重"的节奏有了收益曲线，同时抑制无脑单招循环——节奏感成为可被优化的资源。
3. **时间轴破招**：敌方行动可插入"破招"效果，命中正在构建连携的玩家单位时打断其行动槽序列；玩家同样可用特定连携打断敌方（敌方行动槽机制已在 §12 列为后续阶段，正好一并设计）。**双方时间轴在"打断"点上交汇，就是这套融合系统的核心战场**——连招计划 vs 敌方插队，是"排招"乐趣的来源。

## 三、增量思路逐条评价

总体判断先行：**三份增量思路恰好回应了我评价书最大的结构担忧——战斗与经营/情报脱钩**。它们的方向全部正确，且与"资源即战力"（§3.3）一脉相承。以下是逐条评价与风险提示。

### 3.1 装备系统

**优势**

- 储物装备（低属性/负属性换容量）把"空间管理"支柱直接送进战斗，装备格成为背包与战力的兑换界面，方向极佳；
- "工具人队友背负属性大容量包在安全事件倒卖"是优秀的涌现玩法——它同时调动了小队编制（§10.3）、经营与风险偏好三个系统；
- 角色专长契合、装备格不对称（多手/无腿）、装备解锁新装备格（防弹衣→插板格）为队伍构筑提供身份感；分阶段落地（前期单件/套装、预留接口）的节奏安排正确。

**风险与建议**

1. **富者愈富**：战力来自装备购买（经营输出），若装备获取依赖随机掉落，前期强势局会滚雪球。建议：装备品质按大关/区域分层（§6.1 的大关结构天然适合），并保证确定性的购买/升级路径，随机只影响"用什么"而非"有没有"。
2. **装备格总表必须尽早立**：角色 × 部位 × 遗物槽 × 储物格会快速膨胀为"槽位汤"。纲要阶段先画一张总表，确定每角色装备格数与不对称规则的上限（建议每角色 4-6 格，差异控制在 1-2 格），装备解锁新格设计为稀有事件。

### 3.2 遗物系统

**三份增量中最强的一份。**

**优势**

- "遗物是装备化的特殊效果，通常只对携带角色生效"——对"获取即全局生效"品类惯例的刻意偏离，创造了分配决策（按角色职能调配）；
- **情报驱动换装**（打亡灵前换十字架）把遗物系统挂上了本作的情报支柱——这是全文最"本作气质"的设计：装备决策被情报驱动，情报价值再次被战斗兑现；
- **遗物即货物**（高价值货物参与钱货运营）：卖掉十字架还是留下保命，是纯正的机会成本抉择，与日程抉择的主题完全同构；
- 遗物多为饰品、与普通装备槽生态位错开，槽位冲突可控。

**风险与建议**

1. **换装管理负担**：若每场战斗前都要按情报换装，会成为运营琐事。建议：换装仅在事件之间允许（战斗中锁定）；提供负载配置预设；且**情报永远不完美**——玩家常常只能"猜"下场是什么，换装因此是决策而非例行公事（保留猜错的代价）。
2. **负面遗物的设计标准**：诅咒提灯类负面遗物要"有趣"而非"纯惩罚"——改变玩法的诅咒（如"你的重击变慢但伤害翻倍"）优于数值惩罚（"-10%伤害"）；负面遗物作为高价值货物的估值逻辑也需明确（谁在买诅咒物？→ 本身可以是世界观与情报内容）。
3. **全局生效遗物要稀有且明示**：与品类惯例的偏离是卖点，偶尔的例外是惊喜，比例建议控制在 5% 以内并在界面明示"全局生效"。

### 3.3 技能与库存联动

**方向正确，是本作"资源即战力"最彻底的兑现，但有四个具体问题需要先回答。**

**优势**

- 取消通用"物品"按钮、以技能调用道具：一举消灭传统回合制"无限嗑药"问题——道具使用必须消耗行动槽与时间轴（成本），库存从"兜底资源"变成"构筑资源"；
- "投掷"把药剂、利器乃至货物变为进攻手段：同一件物品**卖掉、使用、投掷**三选一，机会成本主题在道具粒度上再现；
- 库存即构筑：背包里装什么，直接决定战斗里能做什么。

**四个待答问题**

1. **战斗内选物 UI 必须快**。每次投掷都打开全背包浏览会杀死战斗节奏（本作战斗是日程的一环，§10.1 要求决策深度高于操作要求，但操作负担同样受控）。建议：战前"随身绑定"——每角色预先绑定 3-5 个"随身道具"（战术腰带/贴身口袋概念），战斗内只在绑定格中选择。此设计与背包/收纳主题（§9.3）同源，且给"携带空间"新增一层战斗意义（口袋容量 = 战斗道具槽）。
2. **投掷效果需要类别规则表**。不同类别被投掷应有不同效果与手感：药剂=溅射并施加自身效果（对敌投掷 debuff 药剂成为战术！）、利器=按品质计伤害、重货=高伤害但后摇重（呼应轻重节奏）、现金=建议不可投掷（或仅作为彩蛋）。规则表同时防止"任何物品都是 X 伤害"的扁平化。
3. **"检索"技能引入了新系统——法术库**。"从已学习的法术中选择释放"意味着存在一套法术学习系统，当前文档无此系统（§10.4 仅有 4 基础 + 5 连携，§12 技能库来源待定）。建议：法术库的解锁挂到**线索树**——"知识即构筑"（评价书 4.5 第一条），玩家越懂世界、会的法术越多；这是比"商店购买法术"更本作的方案。
4. **投掷/检索在四类技能中的归属**。建议投掷归入 D 类（远程）或单独一类，检索归入 C 类（架势/准备），使它们天然参与连携；并设计少量"道具连携"（如 投掷药剂 + 火系连招 = 爆炸），让库存联动与行动槽系统握手而非平行。

## 四、对评价书 v2 相关结论的更新

| 原结论                                        | 更新                                                                                                                          |
| --------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| 学习友好度 4/10，行动槽是"认知孤岛"           | 包装计划（词汇+图标）与"轻击/重击双系统共用词汇"建议可显著缓解表达层问题；结构层问题保留（成本串长度、UI 点亮即示、M 不入槽） |
| 复杂度控制 5/10，战斗深度与全局注意力预算冲突 | 冲突性质改变：战斗深度的投资方向确定为"经营/情报与战斗的交互密度"，与全局支柱方向一致，不再是孤立堆砌                         |
| 4.6 首推简化行动槽                            | 修改为：结构从简（首版成本串≤3、点亮即示、M 仅中断），深度改由交互承载（读招敌人、节奏奖励、时间轴破招、装备遗物库存联动）    |
| 战斗是"决策的兑现场"                          | 维持并强化：经营/情报的全部决策在战斗兑现，战斗深度投资因此获得全局正当性                                                     |

同时重申：增量思路落地后，**复杂度预算需再审计**——三份增量占用的认知预算应优先从评价书 4.6 的简化清单（多形态货币、委托结算、剪枝级联、概率池稀释）中回收，避免总预算膨胀。

## 五、待总监拍板的问题清单

1. 类别词汇定案方向：轻击/重击/架势/射击四类是否可行？是否接受"四类各一"（§10.4）的约束随词汇重述？
2. 市场用词："搓招"改为"决策式连招/排招"的定位是否接受？
3. 法术库来源：是否采用"线索树解锁"（知识即构筑）？
4. 随身绑定格：是否接受"战前绑定 3-5 个随身道具、战斗内仅从绑定格取用"的规则？
5. 遗物换装时点：是否接受"仅在事件之间允许换装 + 情报不完美"的组合？
6. 节奏奖励与时间轴破招：是否在纲要阶段与敌方行动槽机制一并立项设计？

## 六、下一步建议

1. 上述六个问题定案后，进入战斗系统的纸面原型阶段：一页纸规则 + 桌面试局，验证"排招 vs 敌方插队"的张力是否成立（P0 事项 1 的扩展）；
2. 装备格总表、投掷规则表、遗物生态位说明三份小文档建议在游戏设计纲要阶段前置产出；
3. 建议为战斗系统单独设立一次研讨轮次，议题即本文第五节六问。
