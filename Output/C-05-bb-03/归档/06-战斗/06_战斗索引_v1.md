## 填充顺序建议（依据 B01 结语议题 1）

1. 先完成 10-战斗总览：裁定"决策主角"与复杂度预算（日程 vs 战斗）；
2. 再定 20-时间轴 + 50-行动槽（两套核心规则的词汇统一：轻击/重击等）；
3. 然后展开 40-技能 → 60-装备 → 70-遗物 → 80-库存联动 → 90-敌人AI → A0-战斗目标；
4. 30-战场与战棋规则与 02-时间与事件/40-探索系统共用瓦片，需联调。
