## 1 系统定位

"资源即战力"最彻底的兑现：战斗中使用库存道具不通过传统"物品"按钮，而是通过技能调用（投掷、检索）。库存从兜底资源变成构筑资源——背包里装什么，直接决定战斗里能做什么。

## 2 设计依据（已确定内容摘录）

- 战斗增量思路 3：战斗中使用库存道具需通过技能调用，不像传统游戏有"Item"按钮；
- 投掷技能：对目标造成伤害，选择背包中一件物品投出——可以是药剂、可以是利器；
- 检索技能：造成效果/施加 buff 后，从已学习的法术中选择一个释放。

## 3 研讨增量要点（待拍板）

- B01 战斗研讨 3.3 问题1：战斗内选物 UI 必须快——建议战前"随身绑定"（每角色绑定 3-5 个随身道具，战术腰带/贴身口袋概念），战斗内只在绑定格中选择；口袋容量 = 战斗道具槽——待总监拍板；
- B01 战斗研讨 3.3 问题2：投掷效果需要类别规则表——药剂=溅射并施加自身效果（对敌投掷 debuff 药剂成为战术）、利器=按品质计伤害、重货=高伤害但后摇重（呼应轻重节奏）、现金=建议不可投掷（或仅作彩蛋）——待总监拍板；
- B01 战斗研讨 3.3 问题3：检索技能引入法术库系统——建议法术库解锁挂到线索树（"知识即构筑"）——待总监拍板；
- B01 战斗研讨 3.3 问题4：投掷归入 D 类（远程）或单独一类、检索归入 C 类（架势/准备），使其天然参与连携；并设计少量"道具连携"（投掷药剂 + 火系连招 = 爆炸）——待总监拍板。
