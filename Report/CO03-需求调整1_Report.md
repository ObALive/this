# 1. 任务目标

参照 git 提交 `aabc375cb04d8027d60ff6737f21dcaddc4ba043` 以来上游设计案（架构设计案、系统设计案）的变更，对 `Code_Design/` 现有代码设计案进行调整，使其与最新上游设计一致。核心变化是**项目选用 Unity 引擎并以 C# 实现游戏功能**，要求充分利用引擎的对象模型、生命周期、资源管理与其他原生能力，废弃代码设计中不再必要的重复造轮子方案。

三项执行步骤：

1. **宏观审查**：结合上游变更与引擎选型，审查现有代码设计案的整体文档结构、设计思路与依赖关系，判断是否需要调整整体结构或推翻重做，并说明判断依据；
2. **逐项调整**：逐份检查并修改代码设计文档，落实上游变更，合理采用引擎原生能力，明确必要的自建功能及理由；
3. **完整性检查**：检查调整后的文档之间是否存在职责冲突、依赖错误、设计遗漏或与上游设计不一致的问题。

约束：仅有权修改代码设计文档；严格遵守各层级文档的职责边界；不要机械保留旧设计，也不为使用引擎而盲目引入其功能；所有修改应有明确依据。
