## 1. 任务目标

把《架构设计文档/架构设计案.md》从「与引擎无关的通用架构」改写为**以 Unity 为既定技术环境、在引擎既有机制之上自然设计的架构**。

任务书的核心要求四条：

1. 不是把通用架构「适配到 Unity」，而是直接以引擎的运行机制、对象模型、资源体系、序列化机制、编辑器能力与生命周期机制为设计基础；
2. 架构设计案须逐项判断「引擎是否已提供满足需求的机制」，已提供的直接采用，不重复建设；
3. 自行建设基础设施必须有理由；
4. 最终让程序员能判断「哪些能力直接使用引擎、哪些需要项目自行实现」。

本次执行前，用户就四项口径作出选择：原文件直改（历史交 git）、技术选型走缺口决策系统、写到「机制与职责归属」一级不点名具体 API、本轮只改架构案与出清单不动 `Code_Design/`。

## 6. 执行过程

### 6.1 现状核对

通读任务书、六份规范、现行架构设计案 1551 行、裁定总账 465 行、决策记录 36 行。结论两条：

1. **现行架构案是一份与引擎无关的通用架构**：第 7 章把存档、资源、场景、输入、日志、事件分发、配置、随机、时间九项全部登记为项目自建且「不允许绕过」；
2. **下游耦合极深**：42 份代码设计案共 2,363 处引用架构案；服务容器波及 31 份、数据域与切面波及 42 份、事件分发器波及 38 份、配置服务波及 40 份。

### 6.2 缺口呈报与建库

按任务书要求的「先呈报缺口，再逐项裁定」流程执行：

1. 写出《S02-游戏引擎选型_架构信息缺口分析_v1.md》：判定基准六条、十章逐章影响结论、28 项缺口逐项说明（每项三条互斥候选＋一条推荐）、缺口总表、下游 63 条缺口申报的归并表、与 42 份文档的六类冲突清单、自检；
2. 28 项缺口分四组：A 引擎采用类 10 项、B 结构重写类 4 项、C 上游遗漏类 6 项、D 运行期配套 8 项；
3. 生成建库数据（28 项缺口、84 条候选、每项恰一条推荐），建库并通过结构校验；
4. 建立任务本地工具副本并修正工作区路径；启动填写器服务并验证 28 项可读。

### 6.3 引擎能力核查

独立核查执行体按目标版本逐项抓取引擎官方手册、脚本参考与官方包文档，对十一项基础设施与 28 项候选逐项核对「引擎是否已原生提供」，产出《S02-Unity原生能力核查记录_v1.md》。核查给出的关键事实：

| 结论 | 对本项目的影响 |
| --- | --- |
| 运行时界面方案官方推荐传统场景内界面方案，界面工具包为替代方案 | 界面方案的推荐候选由工程判断升级为有官方定位支撑 |
| 较新版本的新项目默认只重载场景、不重载域 | 常驻单元必须显式复位自身状态，不能依赖域重载 |
| 可等待类型在较早的长期支持版不存在 | 版本基线决定异步能力的可用形态，必须先定基线 |
| 对象池自 2021.1 起原生提供通用池与集合池 | 现行「对象池暂不设立」应改为「通用池用引擎的，项目只设游戏对象池薄封装层」 |
| 引擎自带随机是单一全局流且状态不透明 | 按消费点分流的确定性序列必须项目自建 |
| 时间缩放为零会同时停掉固定步更新与按时长等待 | 「暂停只冻结表现与输入」不能靠时间缩放实现——而本次裁定已全域移除暂停，该风险自然消解 |
| 二进制序列化机制已被明令不得使用 | 第 7 章补禁止项 |
| 存档、配置校验、事件总线、依赖图拓扑、界面栈均无原生对应 | 这五项必须项目自建，写明了自建理由 |

核查后据结论修订了四项候选（常驻对象显式重建、帧循环与暂停、版本基线约束、禁用系统基础库随机），并记入 3 处第 7 章正文修订。

### 6.4 裁定回收

用户在填写器逐项裁定 28 项，结果：**23 项采用候选，5 项自定义方案**。五项自定义方案是本轮的关键取舍：

| 缺口 | 自定义结论 |
| --- | --- |
| `ENG-GAP-002` 对象模型分工 | 不强制规定分工规则，由各系统按实际需要选择承载方式，架构只给原则 |
| `ENG-GAP-005` 序列化机制 | 判别字段式多态序列化：只出现自定义字符串判别值，不写运行时类型名 |
| `ENG-GAP-011` 分层与模块定位 | 分层与模块划分只是「提升代码易读性的自然语言标注」，不承担数据隔离与交互隔离 |
| `ENG-GAP-014` 帧循环与推进 | 半回合制游戏不存在即时操作，选取程序逻辑最方便的即可 |
| `ENG-GAP-018` 退出与终止 | 退出不做任何收尾承诺；一局结束的唯一入口是事件结算环节；并给出验收标准「任意时刻终止进程后重新启动必须能继续游玩」 |

另有若干裁定的补充要求改变了原候选的强度：事件通道由「运行期登记表＋拒绝发布」降级为「类型契约＋一条对账测试」；事件登记改为「即用即定」；依赖登记放宽为「同层只读立通则」；界面清单改为独立文档；暂停全域移除。
