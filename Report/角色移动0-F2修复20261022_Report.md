## 5. 执行过程与技术决定

### F2 修复

`Assets/Script/MetaObjects/MetaObjectPreset.cs`：

1. TryBind 只在尚未绑定时初始化坐标。已绑定重复调用保留组件当前坐标，仍执行现有组件绑定流程。
2. 绑定成功后消费 `hasExplicitCell`，使预绑定暂存不再成为第二个长期坐标来源。
3. 已绑定的 SetCell 直接转发到组件，不再将同一坐标留为陈旧暂存。
4. Rebuild 在释放旧实例前保存组件最新 Cell，作为新实例首次绑定的暂存值；保留坐标组件直接修改的值，也避免从带跨格偏移的世界位置反推时漂移。

没有新增字段监听，关键坐标仍由 SceneCoordinateComponent 私有持有并通过 SetCell 修改。

### R1 方案

详见 `Output/角色移动0-F2修复20261022/角色移动0-F2修复20261022_R1组件替换改进方案_v1.md`。

方案采用组件类型策略标注唯一性；纹理和坐标唯一；Add 只新增，ReplaceComponent 与其同级且显式指定旧、新组件。组件覆写交接方法，自行声明需要继承的状态；以赋值标志区分未赋值和合法零值。新值优先，未赋值项继承旧值，关键值仍无效则拒绝。纹理 Sprite 与路径成组处理，Owner / Preset / 句柄不继承。

元对象统一调度绑定、解绑、交接与替换；替换成功返回时新组件已具备原场景绑定。方案同时覆盖多实例查询、精准替换、重复唯一项拒绝、跨 Owner 拒绝与生命周期异常处理。该方案尚未实现，不把方案签名伪称为已有源码入口。
