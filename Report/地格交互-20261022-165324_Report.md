## 5. 实现与验证过程

GridClickInput.Update 每帧将按下、保持、松开和位置交给 ProcessPointer。输入先判断 UI、视口和当前合法格，再记录原格与范围版本。只有未取消的原格按压可以在松开时发出 CellSelected，业务控制器继续负责移动。

拖出到其他格、视口外或 UI 时立即取消，按住期间不会重新捕获其他格子；范围/行动力变化、禁用和失焦也取消。HoveredCell、PressedCell 仅供表现读取。SubmitScreenPoint 保留既有验证调用方，语义调整为提交一次完整的“按下＋原格松开”，内部经过同一个状态处理入口，不绕过松开受理规则。

MovementRangeOverlay 使用现有框形纹理，通过每格颜色 alpha 改变不透明度，不改共享 Sprite、Tile 或材质。只恢复旧交互格、更新新交互格；整张范围仍仅在范围版本变化时重绘。

默认状态系数：常态 0.5、悬浮 0.8、按住 1.0，乘以原 Tint 和纹理本身的 alpha。Inspector 的 Player → Movement Range Overlay 可调整 Normal Opacity、Hover Opacity、Pressed Opacity。新增字段采用源码默认值，无须重建场景或资产。
