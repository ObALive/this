任务状态按 Started、In Progress、Completed 推进。

1. 读取任务书、项目规则、C 系列通则、上一轮信息缺口分析与受影响的设计稿；

6. 同步系统全景图、域索引、跨系统交互逻辑、术语、设计决策和 README；
7. 保留原信息缺口分析 v1，新建 v2，归档关闭问题，并把剩余缺口细化为 15 个后续问题；
8. 检查必需文件、CSV 行列、旧版引用、公式错误标记和 Git 变更范围。
