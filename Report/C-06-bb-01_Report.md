# C-06-bb-01 任务执行报告

## 1. 任务目标

对 `06-战斗` 域执行系统设计阶段的信息缺口分析：在已有材料与历史回答中检索已有答案，按九条路径逐项推演战斗行为，检查入口、条件、状态变化、资源结算、优先级、输出、反馈与跨系统依赖，合并缺口并按阻塞程度排序，提出可回答的独立决策问题，并明确可继续范围与受阻塞范围。

## 2. 任务书摘要

任务书要求：先在现有材料和历史回答中查找答案，已有答案不重复问；沿正常游玩、条件不足、失败、取消、重复操作、同时事件、退出、读档、恢复逐项推演，无关场景标明不适用理由；检查每项行为的入口、条件、状态变化、资源结算、优先级、输出、反馈与跨系统依赖；检查是否遗漏必要通用系统，是否存在无法继续、重复奖励、资源丢失或相互矛盾的路径；合并缺口并按对当前交接范围的阻塞程度排序；提出独立决策问题，每个问题提供背景、影响、2 至 3 个互斥候选及代价与推荐理由，允许自由答案；明确哪些章节无需等待答案即可继续，不代替用户选择未授权的核心玩法。

输出要求为五部分：覆盖检查表、GAP 表、本轮优先问题包、暂缓问题及原因、当前可继续范围与受阻塞范围及下一步。自检要求为不提出无边界问题，问题可被回答且答案会直接改变明确的规则或范围。
